# Runtime validation; Schema; Type guard

**索引：TS032 · TypeScript**

[领域目录](../domains/typescript.md) · [概念库总目录](../index.md)

## 这是什么

在运行时验证外部数据并连接静态类型

## 什么时候会想到它

当你描述“接口 JSON 类型撒谎”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

写一个类型别名不等于已经做了验证

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

把不可信外部值转换为已验证业务输入。

### 关键特征

- 校验发生在信任边界，静态类型与实际验证规则保持一致。

### 如何落实

- 复用项目已有 schema 或守卫验证字段、枚举、范围及未知键策略，成功后才进入内部类型化逻辑。

### 如何验收

- 缺字段、错误类型、越界值和旧版本负载都得到明确结果，错误可定位到对应路径。

### 常见误用

- 不要只把 JSON 断言成接口，也不要无需求新增校验库或在每层重复解析同一数据。
