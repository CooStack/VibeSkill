# Flex basis/grow/shrink; min-width: 0

**索引：CS013 · CSS**

[领域目录](../domains/css.md) · [概念库总目录](../index.md)

## 这是什么

定义基础尺寸与余量分配并处理固有最小尺寸

## 什么时候会想到它

当你描述“flex 子项挤不下、文本撑破”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

flex: 1 不保证任意内容都自动收缩

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

按内容角色分配弹性空间。

### 关键特征

- basis 决定基础尺寸，grow/shrink 分配余量，自动最小尺寸仍可能限制收缩。

### 如何落实

- 对内容区与操作区分别设伸缩策略；需要截断的内容项设 min-width: 0 或对应逻辑属性并提供溢出策略。

### 如何验收

- 长文件名和窄宽度下内容收缩而按钮不消失，增长后比例和对齐仍符合预期。

### 常见误用

- 不要仅加 flex-shrink 就认为可突破所有最小尺寸，也不要给所有子项套相同 flex 简写。
