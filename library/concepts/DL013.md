# Acrylic; 亚克力材料; Smoke

**索引：DL013 · 设计语言与风格实现**

[领域目录](../domains/design-language.md) · [概念库总目录](../index.md)

## 这是什么

Fluent acrylic 用于临时辅助表面；smoke 弱化模态后方内容。Web 用局部滤镜与独立遮罩近似

## 什么时候会想到它

当你描述“半透明菜单、临时浮层、遮罩”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

Acrylic 和 smoke 不是同一材质；视觉遮罩不自动阻止背景焦点，不能只画黑层就称模态

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

为短暂辅助界面选择 Acrylic 近似，为模态关系选择独立遮罩。

### 关键特征

- 材料表达临时表面与来源内容的关系，不能代替交互模型。
- 模态与非模态必须按实际行为区分。

### 如何落实

- 菜单或轻量浮层使用一个有限区域的半透明表面，必要时加轻微已有噪声纹理；实色回退保留边框，不为纹理增加依赖。
- 普通网页只处理页面背后内容，不声明能像原生 background acrylic 一样透出其他桌面窗口。
- 真正阻断背景操作的弹窗优先使用现有 dialog 组件或 HTML dialog.showModal()；设置名称、合理初始焦点和关闭后的焦点归还。
- smoke 放在 modal 的 backdrop，视觉弱化后方内容；非模态浮层不要无故锁住全页，模态也不能只有遮罩没有焦点约束。

### 如何验收

- Escape、点击外部的约定行为和键盘遍历与模态定义一致，关闭后回到合理触发点。
- 浮层到视区边缘时可重定位或滚动，触发控件及正文不被永久挡住。

### 常见误用

- 并列多片大面积 acrylic 导致边界噪声。
- 用 CSS 黑色蒙层宣称已经实现无障碍模态。
