# java.time; Instant; LocalDateTime; ZoneId

**索引：JV038 · Java 与 JVM**

[领域目录](../domains/java.md) · [概念库总目录](../index.md)

## 这是什么

区分时间线上的点与本地日期时间

## 什么时候会想到它

当你描述“时区错、时间比较”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

LocalDateTime 本身没有时区或偏移

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

时间存储、比较和展示遵守明确的时区及日历语义。

### 关键特征

- 绝对时间点与本地日期时间不可无条件互换。

### 如何落实

- 区分事件瞬间、当地预约及纯日期，选择对应表示。
- 在边界明确 ZoneId 和夏令时歧义处理规则。
- 集中进行序列化与显示转换，测试时注入可控时钟。

### 如何验收

- 跨时区往返后事件仍指向同一瞬间。
- 夏令时重复或缺失的当地时间按约定拒绝或解析。

### 常见误用

- 默认服务器时区等于用户时区；用墙上时间测耗时。
