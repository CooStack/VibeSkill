# RTOS; Real-time operating system

**索引：EM003 · 嵌入式、实时系统与物联网**

[领域目录](../domains/embedded.md) · [概念库总目录](../index.md)

## 这是什么

支持时间约束任务及可分析调度的操作系统

## 什么时候会想到它

当你描述“实时任务调度”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

使用 RTOS 不自动证明整个应用满足截止期限

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

把实时任务需求映射到可分析的调度配置。

### 关键特征

- 使用 RTOS 不自动证明端到端截止期限。

### 如何落实

- 列出任务周期、截止时间、执行预算及共享资源阻塞。
- 按目标内核规则安排优先级与同步，核对中断和高优先级工作干扰。

### 如何验收

- 在组合负载下测响应并对照调度分析假设，记录未覆盖条件。

### 常见误用

- 只提高关键任务优先级，忽略其等待低优先级资源。
