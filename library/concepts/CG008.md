# Depth precision; Z-fighting; Reversed-Z

**索引：CG008 · 计算机图形学与特效**

[领域目录](../domains/graphics.md) · [概念库总目录](../index.md)

## 这是什么

处理有限深度表示和投影分布引起的遮挡误差

## 什么时候会想到它

当你描述“共面闪烁、深度精度”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

reversed-Z 依 API/投影/格式，不是只改深度比较函数

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

减少深度精度不足引起的共面闪烁。

### 关键特征

- 透视深度通常非线性，近平面过近会伤害精度；reversed-Z 需投影、范围、格式和比较状态协同。

### 如何落实

- 先避免无必要共面几何并合理设置近远范围，评估浮点深度与目标 API 支持后再采用一致的反向深度方案。

### 如何验收

- 远景薄面、近景接触及阴影采样分别验证，深度重建与清除值均符合新约定。

### 常见误用

- 只反转深度比较却不改清除和投影，或靠随意偏移所有模型掩盖精度问题。
