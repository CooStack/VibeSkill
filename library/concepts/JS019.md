# async/await

**索引：JS019 · JavaScript**

[领域目录](../domains/javascript.md) · [概念库总目录](../index.md)

## 这是什么

在异步函数中等待 Promise 结果

## 什么时候会想到它

当你描述“异步写成顺序代码”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

await 不让 CPU 密集计算自动脱离主线程

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

以清晰顺序等待真正依赖的异步步骤。

### 关键特征

- await 暂停当前异步流程，不把 CPU 计算移到其他线程。

### 如何落实

- 依赖任务顺序 await，互不依赖任务按限额并发；在捕获边界 await 可能拒绝的调用。

### 如何验收

- 上一步失败不会继续提交下一步，独立请求不被无意串行，提交完成前按钮状态正确。

### 常见误用

- 不要用 forEach(async ...) 期待整体等待，也不要把耗时同步循环放在 async 函数就称为非阻塞。
