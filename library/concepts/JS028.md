# Event target/currentTarget; composedPath

**索引：JS028 · JavaScript**

[领域目录](../domains/javascript.md) · [概念库总目录](../index.md)

## 这是什么

区分事件目标和当前监听对象

## 什么时候会想到它

当你描述“点到图标取错元素”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

Shadow DOM 会影响跨边界传播与重定向

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

从事件中取得正确的目标元素。

### 关键特征

- target 是事件目标，currentTarget 是当前监听节点，shadow 边界可能重定向目标。

### 如何落实

- 固定按钮动作使用 currentTarget，委托按实际 target 查找业务节点；跨 shadow 需要时检查 composedPath 及事件契约。

### 如何验收

- 点击图标、文字和按钮空白处得到同一业务 ID，异步逻辑使用提前保存的必要值。

### 常见误用

- 不要把 target 强制当作按钮，也不要在异步回调里假定 currentTarget 仍保持监听时的值。
