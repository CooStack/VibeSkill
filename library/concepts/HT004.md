## 这是什么

元素有内容模型，空元素不承载子内容

## 什么时候会想到它

当你描述“标签嵌套错、自闭合”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

HTML 与 XML 自闭合解析不能混用

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

遵循元素内容模型避免隐式 DOM 修复。

### 关键特征

- 空元素没有子内容，HTML 不采用任意 XML 自闭合规则。

### 如何落实

- 表格、列表和段落使用允许的子元素；非空原生元素显式闭合，避免交互元素相互嵌套。

### 如何验收

- 解析后节点顺序与预期一致，SSR 输出和客户端模板不会因非法嵌套产生差异。

### 常见误用

- 不要写嵌套按钮或在段落里塞块级结构，或认为普通 div 的斜杠可替代结束标签。
