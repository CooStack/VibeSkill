# AutoCloseable; try-with-resources

**索引：JV016 · Java 与 JVM**

## 这是什么

以词法作用域确定资源关闭

## 什么时候会想到它

当你描述“文件句柄泄露、连接没关”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

GC 不是及时关闭外部资源的替代

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

文件、连接等资源在成功和失败路径上由明确所有者及时关闭。

### 关键特征

- GC 管内存可达性，不负责及时归还外部资源。

### 如何落实

- 标明创建者、借用者及是否转移所有权。
- 适用时以 try-with-resources 围住真实使用范围。
- 检查多资源获取失败、关闭顺序和 suppressed 异常。

### 如何验收

- 在读取或处理阶段抛异常后资源仍关闭。
- 第二个资源创建失败时已创建资源也释放，借用资源不被误关。

### 常见误用

- 返回已经离开资源作用域的惰性结果；关闭非自己拥有的共享连接。
