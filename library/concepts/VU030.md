# Route params/query; Navigation guard

**索引：VU030 · Vue**

[领域目录](../domains/vue.md) · [概念库总目录](../index.md)

## 这是什么

管理 URL 数据及导航过程

## 什么时候会想到它

当你描述“路由参数、登录拦截”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

守卫不代替后端授权；参数变化不必重建组件

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让 URL 参数和导航约束驱动正确数据。

### 关键特征

- 参数变化可能复用组件，守卫是导航控制而非后端授权。

### 如何落实

- 校验 params/query 并转换为业务值，侦听需要的具体参数重新取数；守卫避免循环跳转，离开确认按现有 API 实现。

### 如何验收

- 同路由更换 ID 会加载新记录，旧请求不覆盖新记录，未登录与取消离开时地址和界面一致。

### 常见误用

- 不要只在 mounted 读取一次参数，也不要将 query 值未经验证当作唯一字符串或可信权限。
