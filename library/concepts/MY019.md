# Isolation level; Consistent read; Locking read

**索引：MY019 · MySQL**

[领域目录](../domains/mysql.md) · [概念库总目录](../index.md)

## 这是什么

区分快照读取与带锁读取等可见性规则

## 什么时候会想到它

当你描述“同事务两次读不一致、读最新值”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不同隔离级别、语句及事务时序影响行为

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

并发事务观察到的数据版本和锁行为符合业务决策需要。

### 关键特征

- 一致性读取与锁定读取不同，同名隔离级别需按引擎确认。

### 如何落实

- 读取实际会话隔离设置及事务边界。
- 用两连接时序表描述读、写、提交顺序。
- 针对需要稳定快照或防冲突的步骤选择读取方式并控制事务时长。

### 如何验收

- 两个会话按预定交错执行，观测与所声明隔离语义一致。
- 读后写决策不会因混用快照与当前状态破坏不变量。

### 常见误用

- 把所有 SELECT 都当锁定读取；提高隔离级别却不测等待与死锁。
