# Bento layout; 模块化拼板

[领域目录](../domains/design-language.md) · [概念库总目录](../index.md)

## 这是什么

通过 Grid 的受控跨度区分信息权重，适用于独立且可比较的重复模块

## 什么时候会想到它

当你描述“大小模块、仪表盘拼块、便当布局”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不是页面所有区段都套卡片；卡片不能嵌卡片，窄屏必须回到语义顺序而非缩小整张拼图

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

用受控模块跨度表达独立信息的优先级。

### 关键特征

- 每个模块有独立任务或信息价值。
- 拼板服务内容，不强制所有区段卡片化。

### 如何落实

- 用 CSS Grid 的显式轨道和少量 span 变体安排重复模块，minmax(0, 1fr) 防止长内容撑宽。
- 只有图像或图表等固定格式媒体才设置 aspect-ratio；文字模块按内容生长，不用固定高度裁切。
- 窄屏取消跨列，保留 DOM 顺序；不要用 dense 自动填洞制造视觉与键盘顺序脱节。
- 模块内部用分隔线与排版组织，不再嵌一层卡片；不把页面 header/main 都包装成浮动卡。

### 如何验收

- 增加一倍标题长度和缺少图像时模块仍完整。
- 键盘顺序与视觉顺序一致，手机不缩小整张桌面拼板。

### 常见误用

- 为了填满格子虚构无用指标。
- 不相干内容强行相邻，读者误以为存在关系。
