# Swiss / International Typographic Style; 瑞士排版

**索引：DL015 · 设计语言与风格实现**

[领域目录](../domains/design-language.md) · [概念库总目录](../index.md)

## 这是什么

以共享对齐线、清晰字级、受控行长和图文关系组织信息；用 Grid 实现可重排版面

## 什么时候会想到它

当你描述“严谨网格、大字排版、非对称平衡”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

工程特征摘取，不要求某一字体、固定列数或全站大写；视觉顺序不可破坏 DOM 阅读顺序

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

以网格、字体层级和有序非对称实现 Swiss 启发的排版。

### 关键特征

- 共享对齐线优于零散绝对定位。
- 文字层级与语义阅读顺序一致。

### 如何落实

- 给标题、正文和图像定义共享 Grid 轨道；宽屏允许标题与说明占不同列，窄屏按 DOM 顺序单列。
- 选择项目已有无衬线字体及中文回退，通过字重、字号和行距而非字体数量建立层级；letter-spacing 保持 0。
- 以 max-inline-size 控制正文行长，按真实语言调试；图像与图注共用对齐线，不用空格对齐。
- 用有限强调色关联索引、链接或关键值，装饰性大字不可替代真实标题层级。

### 如何验收

- 关闭 CSS 后标题和段落仍按合理顺序出现。
- 长标题、中文/英文混排和放大文本时网格可重排，无重叠和裁切。

### 常见误用

- 以固定坐标模拟海报后无法适配真实内容。
- 声称只有某一字体或固定列数才符合风格。
