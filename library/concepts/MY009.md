# GROUP BY; HAVING; Aggregate

**索引：MY009 · MySQL**

[领域目录](../domains/mysql.md) · [概念库总目录](../index.md)

## 这是什么

按组计算并筛选聚合结果

## 什么时候会想到它

当你描述“分类统计、聚合后筛选”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

WHERE 与 HAVING 作用阶段不同

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

分组统计的分母、粒度和筛选阶段一致。

### 关键特征

- WHERE 过滤输入行，HAVING 过滤聚合结果。

### 如何落实

- 写清一组代表什么及每项指标的计数对象。
- 先处理连接造成的重复，再选择聚合表达式。
- 按目标 SQL 模式处理非分组字段，明确 NULL 和空组。

### 如何验收

- 用可手算的小数据集核对计数、总和及分组过滤。
- 增加第二条关联明细不会无意重复累计主表金额。

### 常见误用

- COUNT 非空列当总记录数；从每组选取不确定的任意字段。
