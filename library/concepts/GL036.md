# Resource lifetime; Context loss; State restoration

**索引：GL036 · OpenGL 与 GPU 接口**

[领域目录](../domains/opengl.md) · [概念库总目录](../index.md)

## 这是什么

对齐 GPU 资源创建、释放、上下文与引擎状态所有权

## 什么时候会想到它

当你描述“切场景显存泄露、引擎渲染被破坏”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不在无正确上下文的线程直接销毁/操作资源

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

使 GPU 资源与上下文及引擎生命周期一致。

### 关键特征

- 资源句柄有效性依赖上下文和共享规则，状态恢复必须服从引擎所有权而非擅自设为默认。

### 如何落实

- 记录创建与释放责任，在可用上下文中安排清理；对重载、窗口重建或上下文丢失提供重建路径，撤销旧引用。

### 如何验收

- 反复切场景和重载后资源数量稳定，旧句柄不被继续使用，后续渲染状态不受污染。

### 常见误用

- 在任意析构线程直接释放资源，或无差别重置状态破坏调用者正在使用的目标。
