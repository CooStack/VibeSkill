# BigDecimal; Precision; Scale; RoundingMode

**索引：JV039 · Java 与 JVM**

[领域目录](../domains/java.md) · [概念库总目录](../index.md)

## 这是什么

控制十进制精度、尺度和舍入

## 什么时候会想到它

当你描述“小数不准、金额舍入”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

从二进制浮点构造仍可能带入误差

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

十进制计算在约定精度和舍入位置得到一致结果。

### 关键特征

- 金额需明确币种、尺度与舍入时机，而不只是换成 BigDecimal。

### 如何落实

- 从十进制文本或明确的精确表示构造数值。
- 为除法及业务边界指定精度、scale 和舍入模式。
- 明确数值相等与含尺度相等的使用位置。

### 如何验收

- 循环小数除法、负值及舍入临界点符合业务规则。
- 分项求和与总额的差异在约定分摊规则下可解释。

### 常见误用

- 从 double 构造后认为已消除二进制误差；每一步随意舍入。
