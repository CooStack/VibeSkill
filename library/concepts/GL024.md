# sRGB texture; Linear framebuffer; FRAMEBUFFER_SRGB

**索引：GL024 · OpenGL 与 GPU 接口**

[领域目录](../domains/opengl.md) · [概念库总目录](../index.md)

## 这是什么

让颜色纹理与目标在适当阶段进行线性/编码转换

## 什么时候会想到它

当你描述“画面太暗、伽马叠加”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

法线、粗糙度等数据纹理不按颜色一律解码

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

在线性域完成着色与混合并正确输出编码颜色。

### 关键特征

- sRGB 颜色输入需要解码，数据贴图不需要；目标格式与帧缓冲转换状态共同决定输出路径。

### 如何落实

- 列出每张输入及目标的格式，光照在线性域累加，在最终颜色目标按受支持机制编码一次，避免 shader 与目标重复转换。

### 如何验收

- 灰阶、混合边缘和中灰参考正确，离屏到主目标不出现二次变暗或变亮。

### 常见误用

- 只切换 FRAMEBUFFER_SRGB 就假定所有附件自动成为 sRGB，或把 alpha 也按颜色曲线转换。
