# PBO; Readback; Pipeline stall

## 这是什么

用传输缓冲与延迟消费减轻同步回读影响

## 什么时候会想到它

当你描述“截图或读像素导致卡顿”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

异步传输后立刻等待仍可能造成停顿

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

降低读取 GPU 图像到 CPU 的同步停顿。

### 关键特征

- PBO 能延迟 CPU 消费传输结果，立即读取仍可能等待；行布局与目标格式影响结果解释。

### 如何落实

- 将回读写入轮转缓冲，在后续帧用完成信号判断可读，核对 pack 对齐和像素尺寸，并限制排队长度。

### 如何验收

- 截图内容和方向正确，持续回读时帧时间与内存队列保持有界。

### 常见误用

- 调用回读后立刻映射等待，或未完成便重用同一传输区域。
