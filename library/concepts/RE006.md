# Distributed tracing; Span; Context propagation

**索引：RE006 · 可靠性、云基础设施与质量验证**

[领域目录](../domains/reliability.md) · [概念库总目录](../index.md)

## 这是什么

传播上下文关联多段操作，定位延迟和错误路径

## 什么时候会想到它

当你描述“一次请求跨多个服务很慢”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

采样可能遗漏事件；trace ID 不应被当身份凭证

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让跨服务和异步操作保留诊断上下文。

### 关键特征

- 轨迹关系表示操作关联，不是身份认证依据。

### 如何落实

- 在现有传输和任务边界传递受控上下文，明确父子或异步关联。
- 为 span 标注操作与结果，核对异常和取消时也能结束记录。

### 如何验收

- 追踪含异步任务的一次请求，核对缺段、错误关联及采样影响。

### 常见误用

- 复用旧上下文把不同请求串在一起，或让 span 永不结束。
