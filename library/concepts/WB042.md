# 浏览器权限 Permissions; 安全上下文

**索引：WB042 · 网页与 Web 平台**

[领域目录](../domains/web.md) · [概念库总目录](../index.md)

## 这是什么

按受控授权使用敏感能力

## 什么时候会想到它

当你描述“摄像头、定位、剪贴板”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不保证所有浏览器或嵌入环境可用

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

在授权边界内使用摄像头、定位等能力。

### 关键特征

- 用户可拒绝或撤销权限，安全上下文和嵌入策略影响可用性。

### 如何落实

- 在明确操作后按需请求，检测 API 可用性并解释拒绝后的替代路径；结束使用时释放媒体轨道等资源。

### 如何验收

- 首次允许、拒绝、撤销、无设备和嵌入受限情形都有明确结果，离开页面后设备不持续占用。

### 常见误用

- 不要页面打开就反复索权，也不要假定 Permissions API 可统一查询所有能力。
