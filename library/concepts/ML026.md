# Prompt injection; Tool boundary

## 这是什么

区分不可信内容与指令，限制工具权限和外部副作用

## 什么时候会想到它

当你描述“文档叫模型忽略用户指令”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不能只靠一段“忽略恶意文本”的提示词保证安全

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

使不可信内容不能自行获得工具调用权限。

### 关键特征

- 权限边界由执行系统落实，不能只依赖模型服从防护提示。

### 如何落实

- 区分用户授权与文档、网页或工具输出中的指令式文本。
- 在工具执行端校验参数、资源范围和副作用授权，敏感操作保留必要确认。

### 如何验收

- 在隔离样本中嵌入越权读取与外传请求，确认不会转化为未授权工具动作。

### 常见误用

- 把检索文本放入高信任指令位置，或把模型生成的授权理由当真实授权。
