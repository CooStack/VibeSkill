# CORS; 预检 Preflight

**索引：WB006 · 网页与 Web 平台**

[领域目录](../domains/web.md) · [概念库总目录](../index.md)

## 这是什么

服务器声明允许浏览器读取的跨源响应

## 什么时候会想到它

当你描述“跨域报错、OPTIONS”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不是服务端鉴权或 CSRF 防御的替代

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

使授权的跨源请求可被浏览器读取。

### 关键特征

- CORS 是浏览器读取许可，不是服务端身份认证。

### 如何落实

- 按现有部署配置允许的源、方法和头；带凭据时返回明确的允许源，并处理 OPTIONS 预检。

### 如何验收

- 从实际页面源验证普通请求与预检；未授权源不获读取许可，动态允许源的缓存区分 Origin。

### 常见误用

- 不要用 no-cors 期待读到响应，也不要将凭据许可与通配允许源组合。
