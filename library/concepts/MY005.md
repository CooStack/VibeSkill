# NULL; Three-valued logic; IS NULL

**索引：MY005 · MySQL**

[领域目录](../domains/mysql.md) · [概念库总目录](../index.md)

## 这是什么

SQL 条件需处理真、假和未知

## 什么时候会想到它

当你描述“等于空查不到、空值筛选”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

NULL 不等于空字符串或数字零

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

缺失值参与筛选、聚合和关联时不造成静默漏行。

### 关键特征

- SQL 的未知不等于假值零或空字符串。

### 如何落实

- 确定每列 NULL 的业务含义。
- 用 IS NULL 等表达缺失判断，审查 NOT IN、比较及聚合的空值行为。
- 仅在业务允许时用缺省替换，并保留区分缺失的能力。

### 如何验收

- 包含 NULL 的集合执行排除查询时结果符合预期。
- COUNT(*)、COUNT(列) 及外连接样例的数量能逐行解释。

### 常见误用

- 写 col = NULL；无条件 COALESCE 为零改变统计含义。
