# select; option; datalist

## 这是什么

select 约束选择，datalist 提供建议

## 什么时候会想到它

当你描述“下拉选项、可输入建议”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

datalist 不是强制枚举校验

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

区分必须选枚举项和允许自由输入的建议。

### 关键特征

- select 限定选择，datalist 仅提供候选建议。

### 如何落实

- 枚举字段使用稳定 option value，展示标签与存储值分开；允许自由输入时才用建议列表并验证最终值。

### 如何验收

- 重名标签仍提交正确 ID，默认占位不会被当成有效选择，自由输入按业务约定接受或拒绝。

### 常见误用

- 不要把 datalist 当强制枚举校验，也不要提交会随翻译变化的展示文案作为业务 ID。
