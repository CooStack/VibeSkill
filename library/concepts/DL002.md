# Liquid Glass-inspired Web; 苹果玻璃 Web 近似; 网页液态玻璃

## 这是什么

将内容层与功能表面分开，以半透明底色、有限背景滤镜、边缘高光、阴影及明确状态模拟层次；具体 HTML/CSS 见本领域实施指南

## 什么时候会想到它

当你描述“苹果的玻璃风格用于网页，保留可读性；用 HTML/CSS 做苹果玻璃感；苹果风网页文字清晰”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

CSS 可以近似外观和部分响应，不能宣称完全复制原生折射、光照、融合或自动可读性适配

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

用 HTML/CSS 建立受 Liquid Glass 启发的操作层，明确它只是 Web 近似。

### 关键特征

- 先有内容与功能的结构，再给少量功能表面添加材料。
- 前景文字和操作保持清晰；材料增强失败时功能不变。

### 如何落实

- 先复用现有布局与语义：正文、导航、命令分别有合适角色；仅在任务允许结构调整时新增或移动容器，不把整个页面装进透明卡片。
- 基础样式使用不透明背景与成对前景色；只在 @supports 检测通过后，给容器叠加半透明背景及 backdrop-filter，保留 border 和有限阴影。
- 不要设置容器 opacity 来调整透光，否则文字也变淡并可能改变 backdrop root；用 background 的 alpha 单独调整表面。
- 保留原有定位与响应式规则；仅对本来使用 sticky 的区域核对祖先滚动容器、overflow 及焦点遮挡，不为玻璃效果擅自新增吸顶或改变宽度间距。
- 优先沿用现有外观设置与辅助偏好提供实色回退；新增可见开关或持久化设置前确认范围。局部示例是候选路径，不要求照搬；不引入 WebGL 或背景复制追求未经要求的折射。

### 如何验收

- 关闭滤镜支持、切换实色、文字放大和键盘遍历时仍能到达所有内容与动作。
- 在明暗照片、细密正文以及运动背景前测试合成后的对比，不只检查 CSS 前景色与原始背景色。
- 评审说明明确写出“Web 近似”，没有宣称获得系统折射或自动亮度适配。

### 常见误用

- 只有 blur 没有布局、边缘、状态、对比度和回退。
- 把滤镜放在前景 filter 上，模糊文字；复制整页背景造成滚动不同步与额外绘制。
