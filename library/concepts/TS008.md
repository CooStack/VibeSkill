# Literal type; Widening; as const

**索引：TS008 · TypeScript**

[领域目录](../domains/typescript.md) · [概念库总目录](../index.md)

## 这是什么

精确描述常量值并控制推导宽化

## 什么时候会想到它

当你描述“字符串变宽、保留字面值”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

as const 的只读类型约束不是运行时深冻结

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

保留分支判别与常量映射所需的精确值。

### 关键特征

- 字面量宽化受上下文影响，as const 只施加类型层约束。

### 如何落实

- 对固定配置或判别值选择字面量注解或 as const，从常量表提取所需联合，避免不必要的 string 宽化。

### 如何验收

- 拼错状态值被拒绝，判别分支可收窄，外部可变引用不会被误认为已深冻结。

### 常见误用

- 不要对需要编辑的数据随意施加只读字面量，也不要把 as const 当 Object.freeze。
