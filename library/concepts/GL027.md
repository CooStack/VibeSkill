# Viewport; Scissor; Clear

**索引：GL027 · OpenGL 与 GPU 接口**

[领域目录](../domains/opengl.md) · [概念库总目录](../index.md)

## 这是什么

分别配置坐标映射、裁剪区域和缓冲清除

## 什么时候会想到它

当你描述“渲染区域错、只清一块”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

scissor 及写掩码可能影响清除结果

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

正确映射绘制区域并控制局部清除。

### 关键特征

- viewport 映射 NDC 到窗口区域，scissor 限制像素区域，清除还可能受写掩码影响。

### 如何落实

- 根据实际帧缓冲像素尺寸而非逻辑窗口尺寸设置区域，清除前检查剪裁和颜色、深度、模板写掩码。

### 如何验收

- 高 DPI、分屏和离屏缩放下区域准确，整屏清除无残留边条，局部清除不伤邻区。

### 常见误用

- 认为 viewport 会限制 clear，或上一阶段的 scissor 留下未清区域。
