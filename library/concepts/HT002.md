# DOCTYPE; Standards/Quirks mode

**索引：HT002 · HTML**

[领域目录](../domains/html.md) · [概念库总目录](../index.md)

## 这是什么

文档模式影响浏览器兼容行为

## 什么时候会想到它

当你描述“老页面布局异常”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不是声明应用使用哪种 JS 框架

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让页面采用预期的标准布局模式。

### 关键特征

- 文档模式是浏览器兼容行为，不是框架版本声明。

### 如何落实

- 完整 HTML 文档开头保留标准 doctype；排查旧模板、服务端拼接或嵌入文档是否遗漏声明。

### 如何验收

- document.compatMode 为预期的 CSS1Compat，旧页面迁移后盒尺寸未依赖怪异模式。

### 常见误用

- 不要往组件片段反复插入 doctype，或删除它以临时修复某个宽度问题。
