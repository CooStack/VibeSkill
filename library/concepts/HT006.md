# id; class; data-*; dataset

**索引：HT006 · HTML**

[领域目录](../domains/html.md) · [概念库总目录](../index.md)

## 这是什么

分别提供标识、分类与元素附加字符串数据

## 什么时候会想到它

当你描述“定位元素、自定义数据”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

data-* 不替代业务状态库或隐藏敏感数据

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

为元素提供稳定标识和有限附加数据。

### 关键特征

- id 在文档内唯一，class 表达分类，dataset 的值是字符串。

### 如何落实

- 关联标签与控件时生成稳定唯一 ID；data-* 只存必要标识，读取数值或布尔值时显式解析。

### 如何验收

- 重复挂载组件不产生重复 ID，查询和标签关联正确，字符串 "false" 不被误判为真。

### 常见误用

- 不要在 data-* 存凭据或大对象，也不要把 DOM 属性当作另一份业务事实源。
