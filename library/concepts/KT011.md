# Extension function/property; 扩展函数

**索引：KT011 · Kotlin**

[领域目录](../domains/kotlin.md) · [概念库总目录](../index.md)

## 这是什么

在调用语法上扩展可用函数或属性

## 什么时候会想到它

当你描述“给现有类补方法”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

按接收者静态类型解析，不真正修改目标类

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

用扩展语法表达贴近接收者的操作，不改变原类型的成员或动态分派。

### 关键特征

- 扩展按静态接收者类型解析，成员与导入作用域会影响调用。

### 如何落实

- 先搜索已有成员、扩展及调用者，确认语义没有重复。
- 选择最窄合理接收者，明确可空接收者和可见性。
- 检查 Java 调用入口及潜在同名冲突。

### 如何验收

- 以父类型和子类型引用调用时，结果符合静态解析预期。
- 已有调用点没有因导入或重命名转向另一个实现。

### 常见误用

- 期望扩展覆盖成员方法；把跨模块业务依赖藏进通用扩展。
