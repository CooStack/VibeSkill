# Mica; Mica Alt; 云母材料

**索引：DL012 · 设计语言与风格实现**

[领域目录](../domains/design-language.md) · [概念库总目录](../index.md)

## 这是什么

Windows 的不透明基础材料融合主题与壁纸色；Web 以用户主题和少量低饱和底色近似层级

## 什么时候会想到它

当你描述“微软窗口底色、桌面壁纸微染色”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不是实时看穿窗口的毛玻璃；普通网页没有原生桌面壁纸采样能力，不能伪称已取得壁纸

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

区分原生 Mica 基础层与网页可实现的静态主题层。

### 关键特征

- Mica 是不透明基础材料，不能按实时背后模糊解释。
- Web 不假装知道用户桌面壁纸或 Windows 材料设置。

### 如何落实

- 原生窗口按官方材料 API 与目标版本接入，并验证失焦、系统关闭透明和高对比回退。
- Web 用用户选择或应用定义的低饱和背景 token 作为基础层；内容层用连续实色表面与细边界分离。
- 将这种 Web 效果命名为 Mica-inspired theme；不要抓取桌面、请求屏幕共享或增加高成本滤镜来模拟壁纸采样。
- 为亮暗主题分别定义基础背景与内容前景，在禁用效果时仍保留相同布局。

### 如何验收

- Web 示例不依赖桌面权限，也没有宣称背景会随真实壁纸变化。
- 基础层与内容层可区分，普通文字始终位于稳定背景。

### 常见误用

- 把 Mica 与 Acrylic 当成不同 blur 半径。
- 为追求半透明外观反而破坏 Mica 不透明基础层的职责。
