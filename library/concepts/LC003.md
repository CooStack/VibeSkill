# AST; Abstract syntax tree; 抽象语法树

**索引：LC003 · 程序语言与编译系统**

[领域目录](../domains/languages-compilers.md) · [概念库总目录](../index.md)

## 这是什么

保留表达程序含义所需的树结构

## 什么时候会想到它

当你描述“代码变换、语法结构”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

AST 通常不保留全部排版；格式保真需要 token/CST 等信息

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

用 AST 做语义变换并明确不保留的源码信息。

### 关键特征

- 行为保真与注释排版保真需要不同表示支持。

### 如何落实

- 界定要改写的节点、绑定关系及源位置保留需求。
- 沿已有遍历器改写并保持父子与符号关联，需排版保真时保留 token 或具体语法信息。

### 如何验收

- 用相同名字的不同作用域及含注释输入核对变换范围和承诺保留的信息。

### 常见误用

- 仅按节点文本匹配就替换同名符号，误改无关绑定。
