# Responsive style continuity; 响应式风格连续性

**索引：DL026 · 设计语言与风格实现**

[领域目录](../domains/design-language.md) · [概念库总目录](../index.md)

## 这是什么

保留信息优先级和交互模型，按可用空间重排导航、列数与操作区，而非等比缩放

## 什么时候会想到它

当你描述“手机不像桌面、缩放溢出、长文案”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

断点由内容约束决定，不是风格名称给出的固定设备宽度；不得隐藏核心能力来维持截图

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让风格在空间、语言与输入方式变化时仍保持任务连续。

### 关键特征

- 重排结构而不是缩小整页。
- 保留信息优先级、语义顺序和核心能力。

### 如何落实

- 用 minmax、flex-wrap、min-inline-size: 0 和合理换行处理窄列，字号使用 rem 而非随视口连续缩放。
- 由真实内容拥挤点选择断点，侧栏可转披露导航，但必须同步焦点、展开状态和返回路径。
- 为按钮、图标和媒体定义稳定尺寸约束，文字允许增长；不要因 hover 边框或加载标签而改变布局。
- 测试长中文、英文长词、RTL 需要时的逻辑属性、字体失败、横竖屏与软键盘；不通过缩小文字掩盖溢出。

### 如何验收

- 窄屏、桌面及放大文本下无非预期水平滚动、遮挡和不可达动作。
- 对每个断点记录导航与操作区如何变化，任务能力没有只在桌面存在的缺口。

### 常见误用

- 用 transform: scale 缩小整个工具台。
- 为了保持设计截图，裁掉长标签或隐藏必要操作。
