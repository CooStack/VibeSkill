# Tokenization; Context window

**索引：ML020 · 人工智能与机器学习**

[领域目录](../domains/machine-learning.md) · [概念库总目录](../index.md)

## 这是什么

将输入编码为模型单元，受上下文与输出预算约束

## 什么时候会想到它

当你描述“token 超限、上下文太长”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

token 不等于字数；不同模型分词与预算规则不同

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

在模型实际输入预算内保留必要上下文。

### 关键特征

- token 预算按目标模型的计数与接口规则核对，不以字数估算保证。

### 如何落实

- 用项目对应分词或计数设施估算指令、历史、资料和输出预留。
- 按信息优先级截断或摘要，保持消息及结构数据边界完整。

### 如何验收

- 用长文本、多语言和大工具结果核对预算、必需约束保留与超限错误处理。

### 常见误用

- 只截正文而遗漏工具与历史开销，或从中间截断结构化输入。
