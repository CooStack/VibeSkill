## 这是什么

编译器生成目标版本类文件

## 什么时候会想到它

当你描述“编译能过运行版本不支持”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

字节码版本、所用 API 与运行时都要兼容

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

产物能在承诺的最低 Java 环境加载并调用所需 API。

### 关键特征

- 编译器版本、类文件目标版本及可调用 API 是不同约束。

### 如何落实

- 读取构建工具链、release 和部署运行时。
- 按目标版本限制编译 API，并检查依赖产物的最低要求。
- 在最低支持运行时启动实际打包产物。

### 如何验收

- 运行关键入口不会出现类版本或缺方法错误。
- 故意调用目标环境没有的 API 时构建检查能发现。

### 常见误用

- 只设置 target 就认定未引用新 JDK API；在开发 JDK 上测试替代目标运行时测试。
