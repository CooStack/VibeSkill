# Lexer; Tokenization; 词法分析

**索引：LC001 · 程序语言与编译系统**

[领域目录](../domains/languages-compilers.md) · [概念库总目录](../index.md)

## 这是什么

将字符序列识别为词法单元

## 什么时候会想到它

当你描述“把源代码切成 token”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

编程语言 token 与 LLM token 不同

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

将字符输入切分为带位置的明确词法单元。

### 关键特征

- 词法冲突规则及错误字符处理属于语言契约。

### 如何落实

- 列出关键字、标识符、字面量与注释规则及优先级。
- 沿现有词法设施保留偏移和行列，处理未闭合字符串与非法转义。

### 如何验收

- 覆盖相邻运算符、关键字前缀和多行输入，核对 token 序列及位置。

### 常见误用

- 只按空格分割，或错误恢复时不推进输入造成循环。
