# IDOR; BOLA; 对象级越权

**索引：SE019 · 安全与密码学**

[领域目录](../domains/security.md) · [概念库总目录](../index.md)

## 这是什么

在每次资源访问核验主体对该对象的权限

## 什么时候会想到它

当你描述“改订单 ID 看到别人订单”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不可猜 ID 不是授权检查的替代品

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

使对象访问遵守当前主体的资源权限。

### 关键特征

- 不可猜标识只是降低发现概率，不代替对象级授权。

### 如何落实

- 在读取、更新、删除与批量接口中带入可信主体范围。
- 关联子对象时核对其所属父资源，避免只验证其中一个标识。

### 如何验收

- 交换不同用户或租户的对象标识，单条和批量访问都不得泄露或修改越权对象。

### 常见误用

- 列表做了范围筛选，详情或导出入口却按裸 ID 读取。
