# Custom directive; v-html

**索引：VU028 · Vue**

[领域目录](../domains/vue.md) · [概念库总目录](../index.md)

## 这是什么

指令封装元素行为，v-html 写入原始 HTML

## 什么时候会想到它

当你描述“低层 DOM 行为、显示 HTML”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不可信 HTML 需正确清洗，插值文本与其风险不同

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

把低层 DOM 行为与原始 HTML 注入隔离管理。

### 关键特征

- 指令适合元素行为，v-html 绕过普通文本插值的安全边界。

### 如何落实

- 指令在匹配钩子中初始化、更新和清理资源；v-html 仅接收可信或经项目清洗器处理的内容，普通文本仍用插值。

### 如何验收

- 指令反复绑定不留监听，值变化更新正确，恶意事件属性和危险链接不会通过富文本执行。

### 常见误用

- 不要用指令重造完整组件状态，也不要假定 v-html 内容会作为 Vue 模板再次编译或自动清洗。
