## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

在增强能力不可用时保留约定的核心流程。

### 关键特征

- 先明确最低支持环境与基础行为，再渐进添加增强。

### 如何落实

- 尽可能保留链接和表单原生行为；对可选 API 做能力检测，失败时回退到既有可用路径。

### 如何验收

- 关闭某项增强或让资源加载失败后，约定的阅读、导航或提交仍能完成。

### 常见误用

- 不要宣称所有 SPA 都必须无 JS 完整运行，也不要仅用浏览器名称判断能力。
