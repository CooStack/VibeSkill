# Optical cues; Edge highlight; Vibrancy / Refraction

## 这是什么

用边界高光、接触阴影和适度透色提示表面；原生 vibrancy、折射与普通颜色滤镜需分别理解

## 什么时候会想到它

当你描述“边缘发亮、折射感、玻璃有厚度”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

静态 inset shadow 不是光学折射；saturate() 不等于系统 vibrancy，禁止模糊前景文字来冒充材料

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

以有限光学线索提示玻璃边界，而不编造 CSS 折射能力。

### 关键特征

- 高光和阴影只帮助理解表面，不能压过内容。
- 系统 vibrancy、环境响应和 Web 滤镜是不同机制。

### 如何落实

- 将单侧浅色 inset shadow 用作静态边缘提示，外侧低强度阴影表达与内容的距离；不把描边堆成发光霓虹。
- 背景透色使用温和的 saturate 与 blur；前景采用经验证的实色文本，禁止依赖 mix-blend-mode 猜测可读性。
- 装饰伪元素放在文字后方且 pointer-events: none；高光关闭后仍由边框或背景区分可点击区域。
- 若用户明确要求自定义折射实验，另行约定渲染输入、失真方式、兼容性与 GPU 预算；默认 recipe 不升级为着色器任务。

### 如何验收

- 在无阴影和强制颜色模式下仍能识别边界及状态。
- 设计说明将高光标为视觉线索，不写成光学正确或原生等价。

### 常见误用

- 夸大 saturate() 为 Apple vibrancy 的实现。
- 假折射扭曲文字、扩大滤镜区域或穿透相邻内容。
