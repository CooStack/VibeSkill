## 这是什么

通过能力查询组织可回退样式

## 什么时候会想到它

当你描述“新 CSS 不支持怎么办”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

语法支持不一定代表所有组合行为符合预期

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

在支持增强 CSS 时提升表现，其他环境保留可用布局。

### 关键特征

- 先写基础样式，能力查询只开启确需的增强。

### 如何落实

- 用 @supports 检查实际属性值或选择器能力，增强规则局部覆盖；对组合行为仍在目标浏览器验证。

### 如何验收

- 禁用增强规则后内容完整，支持路径没有重复间距或冲突尺寸，核心动作不依赖增强。

### 常见误用

- 不要把语法支持等同所有场景无缺陷，也不要仅为现代语法强行提高项目最低浏览器版本。
