# Data class; copy; Destructuring

**索引：KT006 · Kotlin**

[领域目录](../domains/kotlin.md) · [概念库总目录](../index.md)

## 这是什么

自动提供基于主构造属性的常见操作

## 什么时候会想到它

当你描述“数据对象复制、解构”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

copy 是浅复制，类体属性不都参与自动操作

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

数据对象复制与相等行为符合状态所有权和业务身份。

### 关键特征

- data class 的 copy 是浅复制，自动操作主要依据主构造属性。

### 如何落实

- 检查哪些字段应参与相等及复制。
- 对嵌套可变集合明确共享还是独立快照，必要时复制。
- 避免将不参与相等的类体字段用作关键业务状态。

### 如何验收

- 修改副本的嵌套对象不会意外改原对象，或共享行为有明确契约。
- 相等、哈希和解构结果覆盖业务真正关心的字段。

### 常见误用

- 把 copy 当深拷贝；把含可变成员的数据类直接当稳定 Map 键。
