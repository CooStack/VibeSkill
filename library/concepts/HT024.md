# Web Components; Custom elements; Shadow DOM; slot

**索引：HT024 · HTML**

[领域目录](../domains/html.md) · [概念库总目录](../index.md)

## 这是什么

使用平台组件及封装/内容分发机制

## 什么时候会想到它

当你描述“自定义标签、样式封装”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不等同 Vue 组件、scoped CSS 或 Vue slot

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

以平台组件封装明确的交互边界。

### 关键特征

- Custom Element、Shadow DOM 与 slot 各自解决不同问题，不等于框架组件。

### 如何落实

- 仅在项目需要时注册自定义元素，定义属性与 property 同步、连接清理和事件契约；封装内容通过 slot 分发。

### 如何验收

- 重复连接不累积监听，属性更新可反映到界面，跨 shadow 边界事件和可访问名称符合约定。

### 常见误用

- 不要把 shadow 封装当安全隔离，也不要为普通 Vue 组件复用需求强行引入 Web Components。
