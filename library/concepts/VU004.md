# ref; .value; Unwrapping

**索引：VU004 · Vue**

## 这是什么

以容器跟踪一个可替换的响应式值

## 什么时候会想到它

当你描述“ref 为什么要 value”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

模板、对象属性和集合的自动解包规则不同

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

用 ref 跟踪可整体替换的值。

### 关键特征

- 脚本通常通过 .value 读写，模板及集合中的解包规则并不相同。

### 如何落实

- 沿用项目 Vue API 风格声明 ref，通过同一容器更新值；在数组、Map 等位置明确是否需要 .value。

### 如何验收

- 替换整个列表或标量后视图更新，模板显示的是值而非容器，集合内 ref 访问正确。

### 常见误用

- 不要重新赋值局部变量替代修改 ref.value，也不要假定所有嵌套位置都自动解包。
