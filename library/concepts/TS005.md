# never; void

**索引：TS005 · TypeScript**

[领域目录](../domains/typescript.md) · [概念库总目录](../index.md)

## 这是什么

分别表达无可能值和忽略返回值的特定契约

## 什么时候会想到它

当你描述“不可能出现、函数没返回值”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

void 回调的赋值规则不等同禁止任何返回值

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

区分不可能值与忽略返回值的契约。

### 关键特征

- never 表示无可到达值，void 常表达调用方不使用返回结果。

### 如何落实

- 穷举分支用 never 检查遗漏；为动作回调选择符合实际返回用途的签名，异步回调另行观察 Promise。

### 如何验收

- 新增变体导致穷举位置报错，传给 void 回调位置的异步函数不会留下未处理拒绝。

### 常见误用

- 不要认为 void 类型禁止函数产生任何返回值，也不要用 never 强行掩盖实际可达分支。
