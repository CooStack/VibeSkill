# vue-tsc; Template type checking

**索引：VU035 · Vue**

[领域目录](../domains/vue.md) · [概念库总目录](../index.md)

## 这是什么

检查 Vue 文件的脚本和模板类型

## 什么时候会想到它

当你描述“模板类型没检查、构建通过仍报类型”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

Vite 转译成功不代表完成了完整类型检查

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让 Vue 模板与脚本共同参与类型验收。

### 关键特征

- Vite 转译或页面可运行不代表模板类型检查通过。

### 如何落实

- 复用项目 vue-tsc 命令与匹配的配置，在既有检查流程验证 props、事件载荷及模板表达式。

### 如何验收

- 刻意传错 prop 或访问不存在字段会在目标 .vue 文件报错，正常组件在实际使用配置下通过。

### 常见误用

- 不要为消除错误全局忽略 .vue 文件，也不要未经兼容核对单独升级类型检查器或 TS。
