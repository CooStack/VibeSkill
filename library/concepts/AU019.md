# Listener; Emitter; 2D/3D; Panning; HRTF

## 这是什么

明确听者、发声点和声道格式，再选择声像或双耳空间化

## 什么时候会想到它

当你描述“声音从哪来、转镜头方向不对”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

HRTF 不是混响或距离衰减；相机与角色不一定同位，耳机处理不宜重复叠加

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让世界声源方向可信，同时避免把 UI 或空间底床错误地附着在世界点上。

### 关键特征

- 先确定 listener 与声源，再选择声道布局和空间化方法。
- 方向、距离和混响是不同控制，不应同时乱调来猜问题。

### 如何落实

- 写明 UI、角色自身、场景点声源及环境底床各自的 2D/3D 策略，保留现有玩法视角。
- 固定声源并旋转 listener，再固定 listener 移动声源，单独检查左右、前后与近距行为。
- 空间化插件或系统耳机处理存在时核对是否重复应用；针对扬声器与单声道另行检查回退。

### 如何验收

- 相机与角色分离、观战或视角切换时，listener 归属仍符合设计。
- 重要信息在单声道下不因宽化抵消，方向丢失时有适合玩法的其他提示。

### 常见误用

- 把立体声素材直接当作理想点声源。
- 把 HRTF、距离衰减和混响混为一个开关。
