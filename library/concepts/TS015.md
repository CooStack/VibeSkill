# Type assertion; 类型断言; as; Non-null assertion

**索引：TS015 · TypeScript**

[领域目录](../domains/typescript.md) · [概念库总目录](../index.md)

## 这是什么

告知编译器按开发者断言解释类型（S24）

## 什么时候会想到它

当你描述“强制转类型、感叹号消报错”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不执行运行时转换或空值检查

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

仅在有外部证据时使用类型断言。

### 关键特征

- as 与非空断言不转换值，也不在运行时检查空值。

### 如何落实

- 优先通过校验或控制流证明；无法表达的库边界只做局部断言，并保留对应生命周期或形状检查。

### 如何验收

- 断言前的假设在空值、卸载和外部错误数据下仍受保护，移除断言不会暴露未处理的业务分支。

### 常见误用

- 不要用 as unknown as 连续跨越不兼容类型，也不要为消红线给所有 DOM 查询加 !。
