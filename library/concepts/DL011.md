# Fluent 2; Fluent design language

**索引：DL011 · 设计语言与风格实现**

[领域目录](../domains/design-language.md) · [概念库总目录](../index.md)

## 这是什么

区分 solid、mica、acrylic、smoke 的职责，以稳定导航、内容区域及可扫描状态支持工作流

## 什么时候会想到它

当你描述“微软风格、工作台、清晰分层”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

Fluent 不是全屏透明；Web 借鉴语义与布局，不自动获得 Windows 材料和系统窗口状态

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

构建 Fluent 启发的稳定工作布局，并按职责使用材料。

### 关键特征

- solid 是常用承载面，其他材料各有明确位置。
- 导航、命令和内容层级稳定，状态信息易扫描。

### 如何落实

- 以 nav、main 和可选 inspector 建立工作区，使用 Grid 的 minmax(0, 1fr) 防止内容列撑出。
- 将命令分组置于固定位置的工具区，重复数据用表格或列表；按任务决定是否需要 inspector，不为了风格增加第三栏。
- 内容层采用 solid；临时菜单才选择 acrylic 近似，模态遮罩才使用 smoke 语义，底层主题色按 DL012 处理。
- 建立中性前景、交互强调、选中与错误语义色；hover、focus-visible 和选中状态分开定义。

### 如何验收

- 隐藏非必要装饰后仍能识别当前导航、选中对象和操作范围。
- 小窗口下检查侧栏收起、焦点归还、内容列宽和命令可达性。

### 常见误用

- 把每个表格单元和面板都做半透明。
- 把窗口失焦行为直接用网页 hover 代替。
