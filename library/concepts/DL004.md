# Regular / Clear Liquid Glass; 材料变体

**索引：DL004 · 设计语言与风格实现**

[领域目录](../domains/design-language.md) · [概念库总目录](../index.md)

## 这是什么

Apple regular 更重视背景处理与可读性；clear 用于照片视频等丰富背景上的控件，必要时加局部衬底

## 什么时候会想到它

当你描述“玻璃更通透、照片上有控件、文字多”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

原生变体不是两档 CSS blur；Web 应按内容风险定义自己的实色/半透明层，不宣称数值等价

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

按背景复杂度和文字负担选择玻璃的可读性策略。

### 关键特征

- 原生 regular/clear 是系统变体，不是可直接换算成 CSS 数值的参数。
- 媒体沉浸感不得优先于暂停、返回等必要操作的可见性。

### 如何落实

- 原生有较多文字、侧栏或复杂背景时优先核对 regular 的用法；照片/视频上少量控件才考虑 clear。
- Web 定义自己的 readable 与 media-overlay 语义变体：readable 使用较强实色衬底，media-overlay 保留媒体但给按钮独立稳定背景。
- 对于不可预测的视频帧，给控件区域放局部暗色或亮色衬底，避免逐帧采样整幅画面作为默认方案。
- 不要直接照搬某个官方示意图的遮罩百分比；用实际文字、背景范围和对比结果决定 Web 参数。

### 如何验收

- 分别覆盖全白、全黑、明暗交界和字幕穿过控件的画面。
- 扩大文字、显示长语言标签后仍清楚，不能为了通透删除标签。

### 常见误用

- 把 clear 当成所有页面都更高级的默认选项。
- 用纯白图标加文字阴影替代真实对比评估。
