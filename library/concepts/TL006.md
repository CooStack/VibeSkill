# Toolchain; source/target compatibility; jvmTarget

## 这是什么

控制使用的工具和目标字节码/API 约束

## 什么时候会想到它

当你描述“编译 JDK 和运行 JDK 不同”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

javac release 与只设置 target 的保障不同

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

编译工具、字节码及 API 使用范围与运行环境一致。

### 关键特征

- toolchain 选择工具，目标设置约束产物；二者不能互相替代。

### 如何落实

- 读取 Java、Kotlin 编译任务和最低部署版本。
- 对齐 toolchain、release 或对应目标设置，核对插件支持。
- 检查依赖类文件及运行时库要求。

### 如何验收

- 混合 Java/Kotlin 产物在最低目标环境加载运行。
- 不会因本机较新 JDK 而静默引用目标缺失 API。

### 常见误用

- 只改 jvmTarget 就解决所有 JDK API 兼容；随意升级构建环境。
