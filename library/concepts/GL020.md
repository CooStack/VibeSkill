# Sampler; Texture unit; Image unit

## 这是什么

区分纹理采样绑定与图像读写绑定

## 什么时候会想到它

当你描述“多张贴图、采样器绑定错”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

sampler uniform 的整数通常指定纹理单元，不是纹理对象 ID

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让着色器从正确纹理单元读取数据。

### 关键特征

- sampler uniform 通常存纹理单元编号而非对象 ID；image 读写绑定属于另一套接口。

### 如何落实

- 为各输入列出单元、纹理目标、采样器状态和数值类型，逐项绑定；图像写入后供采样使用时处理访问可见性。

### 如何验收

- 多张明显不同的测试纹理可定位每个输入，整数、深度比较和普通颜色采样器与格式匹配。

### 常见误用

- 把纹理对象句柄填进单元索引，或以为绑定 image 同时完成了 sampler 绑定。
