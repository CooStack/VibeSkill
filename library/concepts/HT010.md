# input type; name; value; FormData

**索引：HT010 · HTML**

[领域目录](../domains/html.md) · [概念库总目录](../index.md)

## 这是什么

类型决定输入语义，name 参与提交数据键

## 什么时候会想到它

当你描述“取表单值、字段没提交”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

DOM id 不等于提交字段名

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

按原生表单规则收集字段数据。

### 关键特征

- name 决定提交键，控件类型决定值的语义与收集方式。

### 如何落实

- 为需要提交的字段设置 name，使用 FormData 获取成功控件；重复字段用 getAll，文件保留 File 对象。

### 如何验收

- 多选、复选框、文件和同名字段的负载正确，未勾选或禁用字段的缺失有明确含义。

### 常见误用

- 不要把 id 当作字段名，或用普通对象赋值无意覆盖重复键。
