# TypeScript; TS; Type erasure

**索引：TS001 · TypeScript**

## 这是什么

在 JavaScript 上进行静态检查，类型信息大多被擦除

## 什么时候会想到它

当你描述“TS 类型运行时去哪了”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

某些 TS 语法有运行时输出，不能概括为全都无输出

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让静态约束与运行时实现各负其责。

### 关键特征

- 多数类型信息被擦除，声明的类型不会自动检查外部数据。

### 如何落实

- 沿用项目编译流程执行类型检查，外部输入另做运行时校验；使用有输出的 TS 语法前确认工具链支持。

### 如何验收

- 产物不依赖已擦除的接口或别名作为运行时值，错误 JSON 在运行时边界被拒绝。

### 常见误用

- 不要把转译成功等同类型检查通过，也不要概括所有 TS 语法都没有运行时产物。
