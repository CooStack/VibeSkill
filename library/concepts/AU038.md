# Reference listening; Level-matched A/B; 试听验收

**索引：AU038 · 音效设计与游戏音频**

[领域目录](../domains/audio.md) · [概念库总目录](../index.md)

## 这是什么

固定场景、播放链路和监听设置，对同一语义做响度相近的对比及盲辨

## 什么时候会想到它

当你描述“独听很帅进游戏很糊、改了不知道更好没”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

“更响”容易被误判成“更好”；响度匹配是比较控制，不要求最终资产同响度

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

判断声音修改是否改善用户目标，而不被响度或独听效果误导。

### 关键特征

- 固定场景和播放链路，每次只检验少量变量。
- 同时评价识别、情绪与长期使用，不把个人喜好当作唯一证据。

### 如何落实

- 保存同一动作和背景的重放轨迹，以相近试听响度比较原版与改版，隐藏版本标签减少偏好暗示。
- 依次测试独听、正常混音和最高事件密度，记录是哪一时刻、哪个层或哪个语义失效。
- 换耳机、扬声器和单声道复查，并邀请目标用户描述听到的事件；控制监听设置且适时休息，不靠不断调大音量找细节。

### 如何验收

- 改进能用具体目标描述，如格挡与命中更易区分，而非仅波形更满。
- 保留未测试设备和受测人数等限制，不声称普遍适用。

### 常见误用

- 比较不同音量或不同背景下的版本。
- 只听一次重击，不听连续操作后的疲劳和尾声堆积。
