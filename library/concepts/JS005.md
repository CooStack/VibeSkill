# Optional chaining; ?.

**索引：JS005 · JavaScript**

[领域目录](../domains/javascript.md) · [概念库总目录](../index.md)

## 这是什么

对 nullish 接收者短路访问或调用

## 什么时候会想到它

当你描述“深层属性可能不存在”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不吞掉任意异常，也不使未声明变量安全

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

安全访问可缺失的对象路径。

### 关键特征

- 可选链只对 nullish 接收者短路，不吞掉任意异常。

### 如何落实

- 在真正可缺失的层放置 ?.，按业务补 ?? 后备；必需数据缺失仍进入明确错误路径。

### 如何验收

- 上层对象缺失时不抛属性访问错误，方法内部异常仍可观察，合法 false 或 0 不被替换。

### 常见误用

- 不要靠可选链隐藏违反契约的数据，也不要认为 obj.method?.() 可使非函数值变得可调用。
