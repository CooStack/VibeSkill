# CSRF; SameSite; 防伪令牌

**索引：WB009 · 网页与 Web 平台**

[领域目录](../domains/web.md) · [概念库总目录](../index.md)

## 这是什么

防止浏览器附带身份凭据执行非预期操作

## 什么时候会想到它

当你描述“被诱导发请求、跨站提交”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

Cookie 属性及令牌策略需结合实际场景

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

阻止借助浏览器身份凭据伪造状态变更。

### 关键特征

- 自动携带 Cookie 的请求需要明确的跨站防护策略。

### 如何落实

- 沿用服务端防伪令牌及来源校验，按登录流程配置 SameSite；状态变更不走 GET。

### 如何验收

- 缺失或错误令牌的跨站提交被拒绝，正常登录跳转和合法提交仍能完成。

### 常见误用

- 不要把 CORS、隐藏按钮或仅设置 HttpOnly 当作完整 CSRF 防护。
