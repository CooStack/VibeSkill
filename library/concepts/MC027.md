# Data Pack; 数据包; pack.mcmeta; Pack format

**索引：MC027 · Minecraft / 我的世界**

## 这是什么

以目标版本支持的数据资源扩展服务器逻辑/内容

## 什么时候会想到它

当你描述“不写 Java 添加配方、游戏数据”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不是可以执行任意 JVM 代码的模组

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

用数据包提供目标版本能解析的服务器数据内容。

### 关键特征

- 数据包扩展受支持的数据资源，不能代替任意 JVM 代码或客户端资产。

### 如何落实

- 核对目标版本 pack 格式与目录命名，使用独立命名空间组织配方、标签或函数，重载后检查解析日志与覆盖顺序。

### 如何验收

- 干净世界及目标整合包均能加载，缺失引用会被发现，移除包后的行为符合预期。

### 常见误用

- 混用不同版本目录名，或把贴图放进数据域并期待客户端显示。
