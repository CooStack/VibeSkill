# disabled; readonly; hidden input

**索引：HT012 · HTML**

[领域目录](../domains/html.md) · [概念库总目录](../index.md)

## 这是什么

禁用、只读和隐藏字段具有不同交互/提交行为

## 什么时候会想到它

当你描述“不可编辑但要提交”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

禁用控件通常不参与表单提交；隐藏不等于安全

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

按交互与提交需求选择禁用、只读或隐藏。

### 关键特征

- disabled 通常不参与提交，readonly 仅适用于支持它的控件。

### 如何落实

- 不可编辑但需提交的受支持字段使用 readonly；隐藏字段只承载必要数据，服务端仍重新验证可信性。

### 如何验收

- 实际 FormData 包含所需值，禁用控件不能操作，只读值仍可读取或复制。

### 常见误用

- 不要认为 hidden 可保护价格或身份，也不要给 select 加 readonly 期望原生生效。
