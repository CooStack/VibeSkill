# Connection pool; Prepared statement; Parameter binding

**索引：MY027 · MySQL**

## 这是什么

复用连接并把值参数与 SQL 结构分离

## 什么时候会想到它

当你描述“连接耗尽、防 SQL 注入”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

标识符和排序方向通常不能直接当值参数绑定

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

连接有界复用，查询值与 SQL 结构分离。

### 关键特征

- 池容量与数据库承载匹配；预编译并不授权动态拼接标识符。

### 如何落实

- 定义获取连接预算并在所有路径归还连接。
- 使用参数绑定传值，列名和方向映射到允许集合。
- 检查归还时事务、会话设置及失效连接处理。

### 如何验收

- 异常和超时后活动连接数回落。
- 恶意字符串不能改变语句结构，池耗尽时错误有界且可观察。

### 常见误用

- 扩大池掩盖慢查询；归还尚未提交或回滚的连接。
