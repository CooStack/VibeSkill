## 这是什么

布尔属性通常以是否出现表达真值

## 什么时候会想到它

当你描述“disabled=false 仍禁用”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

字符串 false 不等于布尔 false

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让属性声明与运行时控件状态一致。

### 关键特征

- 布尔属性以存在表示真，attribute 与 property 的反射规则因属性而异。

### 如何落实

- 原生 DOM 用对应布尔 property 或 toggleAttribute；模板使用布尔绑定，区分默认值与当前 value/checked。

### 如何验收

- false 时 disabled 属性被移除或 property 为 false，用户修改后的当前值不会被默认属性误读。

### 常见误用

- 不要输出 disabled="false"，也不要把 ARIA 的字符串状态当作 HTML 布尔属性处理。
