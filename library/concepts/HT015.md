# textarea; Text content; value

**索引：HT015 · HTML**

[领域目录](../domains/html.md) · [概念库总目录](../index.md)

## 这是什么

区分源文档默认内容与运行时当前值

## 什么时候会想到它

当你描述“多行输入默认值不同步”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不用 innerHTML 设置用户输入文本

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

准确管理多行输入的初始值和当前值。

### 关键特征

- textarea 的文档文本表示默认内容，value 表示当前编辑内容。

### 如何落实

- 按受控模式同步 value，或用默认内容初始化；读取当前 value，明确表单 reset 后恢复的基线。

### 如何验收

- 用户编辑、程序赋值、提交和重置得到各自预期内容，换行不丢失。

### 常见误用

- 不要用 innerHTML 写入用户文本，或持续读 textContent 作为当前输入值。
