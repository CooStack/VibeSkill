# Adapter; 适配器

**索引：DP007 · 设计模式**

[领域目录](../domains/design-patterns.md) · [概念库总目录](../index.md)

## 这是什么

将现有接口转换为调用方期望的接口

## 什么时候会想到它

当你描述“接口不兼容、接旧系统”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

不应悄悄改变关键业务语义

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

旧接口被转换成调用方契约时，单位、错误和资源语义不失真。

### 关键特征

- 适配不应悄悄改变业务含义，不要求改造被适配系统。

### 如何落实

- 逐项对应参数、结果、缺省、异常及同步异步语义。
- 在单一边界完成转换并明确资源所有权。
- 无法等价适配的部分显式拒绝或暴露限制。

### 如何验收

- 同一契约测试可覆盖原实现和适配实现。
- 单位边界、空值和下游失败不会被误转成成功。

### 常见误用

- 吞掉不支持能力；为接一个旧 API 重写整个核心接口。
