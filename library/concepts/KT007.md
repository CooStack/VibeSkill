# Sealed class/interface; enum class

**索引：KT007 · Kotlin**

[领域目录](../domains/kotlin.md) · [概念库总目录](../index.md)

## 这是什么

受限类型层级或固定实例集表达变体

## 什么时候会想到它

当你描述“有多种数据形态的状态”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

子类允许范围和穷举行为依平台/版本核对

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

状态变体携带各自合法数据，使非法组合难以表达。

### 关键特征

- 枚举适合固定实例，sealed 层级适合具有不同数据形态的变体。

### 如何落实

- 列出真实状态及每种状态必需字段。
- 以受限变体表示互斥情况，并保留边界的未知值策略。
- 在状态处理处使用穷举分支并核对目标平台限制。

### 如何验收

- 新增变体时遗漏处理能被编译或测试发现。
- 不能构造既成功又失败或成功却缺结果的状态。

### 常见误用

- 所有 when 都加无意义 else 掩盖漏处理；假定外部数据永远只有已知变体。
