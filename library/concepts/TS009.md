# interface; type alias; Declaration merging

**索引：TS009 · TypeScript**

[领域目录](../domains/typescript.md) · [概念库总目录](../index.md)

## 这是什么

声明对象契约或命名任意类型表达式

## 什么时候会想到它

当你描述“接口还是类型别名”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

并非所有类型别名都能由 interface 替代

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

为契约选择符合扩展方式的命名形式。

### 关键特征

- interface 可声明合并，type 能命名联合等表达式；沿用现有风格。

### 如何落实

- 对象公共契约按项目约定组织，联合或复杂类型运算使用别名；只有明确扩展点才依赖声明合并。

### 如何验收

- 扩展后的契约无冲突，同名声明不会意外合并改变所有使用方。

### 常见误用

- 不要为风格偏好全量替换接口与别名，也不要认为二者在所有表达能力上完全等价。
