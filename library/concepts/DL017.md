# Web brutalism; 网页粗野主义

**索引：DL017 · 设计语言与风格实现**

[领域目录](../domains/design-language.md) · [概念库总目录](../index.md)

## 这是什么

暴露内容结构与链接关系，使用强边界、直接排版和较少装饰层，保留浏览器语义

## 什么时候会想到它

当你描述“原始、直接、粗线、非精修感”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

无统一工程规范；故意难读、破坏导航、布局溢出不是风格必需，也不等于建筑定义

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

实现直接、结构外露的 Web brutalist 表达而保留可用性。

### 关键特征

- 直接呈现信息和链接，不依赖精致材质建立层级。
- 视觉粗粝不意味着交互故障。

### 如何落实

- 保留语义 heading、list、table 和原生链接，以清楚分隔线和较强字重建立结构。
- 使用有限字体、明确下划线和直接的操作文案；长内容通过正常流排版而非任意错位。
- 选用对比足够的背景/文字组合，可以出现粗边界，但为按钮定义明确 focus-visible 与 disabled 状态。
- 只在不影响阅读的装饰区域使用非规则构成，避免水平滚动、遮挡和假系统错误。

### 如何验收

- 键盘和屏幕阅读顺序合理，链接目的可识别。
- 窄屏下粗边框计入 box-sizing，内容不被固定宽度挤出。

### 常见误用

- 故意破坏表单、可读性或导航来证明风格。
- 把建筑领域的词源直接当作 Web 界面的完整历史定义。
