# any; unknown

**索引：TS004 · TypeScript**

[领域目录](../domains/typescript.md) · [概念库总目录](../index.md)

## 这是什么

any 放宽检查，unknown 要先收窄后使用

## 什么时候会想到它

当你描述“不知道类型、接口返回任意数据”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

unknown 更适合未验证输入，但本身不验证内容（S24）

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让未验证输入在证明前不可直接使用。

### 关键特征

- unknown 要求收窄，any 会传播并绕开大量检查。

### 如何落实

- 外部 JSON 或异常先视为 unknown，通过真实字段和类型判断收窄；遗留 any 隔离在最小适配边界。

### 如何验收

- 未收窄值不能直接访问业务字段，合法与畸形输入分别进入成功和错误路径。

### 常见误用

- 不要在 unknown 后立刻 as any，也不要把 unknown 本身当已完成验证。
