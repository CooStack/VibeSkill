# Vertex; 顶点; Vertex attribute

**索引：GL003 · OpenGL 与 GPU 接口**

[领域目录](../domains/opengl.md) · [概念库总目录](../index.md)

## 这是什么

GPU 输入顶点通常是一组位置及其他属性，不只是一个坐标点

## 什么时候会想到它

当你描述“Vertex 数据、位置颜色 UV”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

同一空间点因法线/UV 不同可能需要多个渲染顶点

## 例子

立方体一个角在空间中只有一个位置，但三个相邻面可能需要不同法线或 UV。因此索引网格中的渲染顶点可能要拆开，不能只按位置相同就把所有顶点合并。
