# Interruption; ThreadLocal

**索引：JV032 · Java 与 JVM**

## 这是什么

中断表达协作取消，线程局部变量绑定线程

## 什么时候会想到它

当你描述“取消线程、请求上下文串了”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

线程复用需清理；上下文不自动跨异步传播

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

取消信号不被吞掉，请求上下文不随线程复用泄露。

### 关键特征

- 中断是协作信号；ThreadLocal 归属线程而非逻辑请求。

### 如何落实

- 为阻塞点和计算循环设计中断响应。
- 无法向上抛出中断时按契约恢复标志并结束适当工作。
- 用 finally 清理线程局部数据，跨异步边界显式传递必要上下文。

### 如何验收

- 取消后任务在声明边界结束并释放资源。
- 同一池线程连续处理两个用户时不串身份或追踪信息。

### 常见误用

- 空捕获 InterruptedException；假定 ThreadLocal 自动跨线程传播。
