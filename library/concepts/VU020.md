# Template ref; defineExpose

**索引：VU020 · Vue**

[领域目录](../domains/vue.md) · [概念库总目录](../index.md)

## 这是什么

在挂载后引用元素或显式暴露的组件接口

## 什么时候会想到它

当你描述“父调用子方法、拿 DOM”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

ref 可能尚未存在或因条件渲染变为 null

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

仅在需要命令式能力时访问 DOM 或子组件。

### 关键特征

- 模板引用在挂载前或条件卸载后可能为空，公开接口应最小化。

### 如何落实

- 使用版本支持的模板 ref 方式，更新后按需等待 nextTick；子组件用 defineExpose 暴露必要的 focus/reset 等动作。

### 如何验收

- 首次打开、快速关闭和再次挂载不会访问空引用，父级只能依赖声明的公开方法。

### 常见误用

- 不要用非空断言掩盖条件渲染寿命，也不要让父级直接修改子级全部内部响应式状态。
