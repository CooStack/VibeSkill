# Memory mapping; mmap; 文件映射

**索引：OS010 · 操作系统与系统编程**

[领域目录](../domains/operating-systems.md) · [概念库总目录](../index.md)

## 这是什么

将文件或共享对象映射到地址空间

## 什么时候会想到它

当你描述“大文件映射读取、共享内存”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

映射成功不表示所有页已加载，也不保证写入已持久化

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

为文件或共享对象映射定义访问和持久化责任。

### 关键特征

- 映射建立、页可访问与数据持久化分别判断。

### 如何落实

- 明确映射长度、访问权限、对象大小变化和解除映射责任。
- 按平台契约处理并发写入与持久化；不让视图活过底层映射。

### 如何验收

- 验证边界访问、关闭后引用和约定的截断场景，持久化要求另做恢复验证。

### 常见误用

- 把映射成功视为全部页已就绪，或当作自动事务。
