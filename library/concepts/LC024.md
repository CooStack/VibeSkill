# FFI; Foreign function interface

**索引：LC024 · 程序语言与编译系统**

[领域目录](../domains/languages-compilers.md) · [概念库总目录](../index.md)

## 这是什么

在不同语言/运行时之间桥接调用与数据

## 什么时候会想到它

当你描述“Java 调原生库、跨语言互调”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

需明确 ABI、所有权、异常边界和线程约束

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

为跨语言调用建立编码、错误与资源契约。

### 关键特征

- FFI 需要同时满足 ABI 和两端运行时限制。

### 如何落实

- 明确字符串编码、长度、缓冲拥有者及释放方。
- 在边界转换错误，按目标运行时核对线程附着、回调寿命和异常传播方式。

### 如何验收

- 用空值、非 ASCII 文本、回调取消和错误返回验证双向调用与回收。

### 常见误用

- 让异常越过不支持的边界，或由另一分配器释放内存。
