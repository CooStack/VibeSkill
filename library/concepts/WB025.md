# ARIA; 可访问名称 Accessible name

## 这是什么

向辅助技术表达名称、角色与状态

## 什么时候会想到它

当你描述“图标按钮读什么”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

优先原生语义；ARIA 不会自动添加交互

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

使辅助技术读到准确的控件名称与状态。

### 关键特征

- ARIA 补充缺失语义，不自动实现键盘交互。

### 如何落实

- 优先原生角色，用可见文字或 aria-labelledby 建立名称；状态变化同步 aria-expanded、aria-checked 等适用属性。

### 如何验收

- 可访问树中名称与可见用途一致，展开收起后状态同步，引用的标签 ID 确实存在。

### 常见误用

- 不要给普通动作按钮套菜单角色，或用 aria-label 覆盖掉有意义的可见名称。
