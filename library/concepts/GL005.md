# VAO; Vertex array object; Attribute layout

**索引：GL005 · OpenGL 与 GPU 接口**

[领域目录](../domains/opengl.md) · [概念库总目录](../index.md)

## 这是什么

保存顶点输入状态及相关缓冲引用（S49）

## 什么时候会想到它

当你描述“绑定了 VBO 却画不出、顶点格式”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

VAO 不复制顶点内容；索引缓冲绑定也有 VAO 关联

## 例子

准备好 VBO 后还需要让顶点输入状态知道每条记录有多长、位置和 UV 各在什么偏移。VAO 记录这类状态和关联，而不是把顶点数组复制一遍。排查时同时检查启用属性、索引缓冲及实际绑定对象。

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让 VAO 正确解释顶点和索引缓冲。

### 关键特征

- VAO 保存顶点输入状态和相关缓冲引用，不复制缓冲数据；传统属性配置会捕获当时的源缓冲关联。

### 如何落实

- 在正确上下文和 VAO 下配置已核对的属性位置、源缓冲、类型与启用状态，建立索引缓冲关联后再执行绘制。

### 如何验收

- 捕获帧中的属性能还原预期位置和 UV，切换两个 VAO 不串用索引或布局。

### 常见误用

- 配置后解绑索引缓冲却无意修改当前 VAO，或以为换绑 VBO 就自动改好了已有属性关联。
