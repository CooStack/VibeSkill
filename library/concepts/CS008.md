## 这是什么

单位分别依赖 CSS 像素、字体或参考尺寸

## 什么时候会想到它

当你描述“字号和高度按什么算”这类需求时，可以把本条作为候选概念。
是否采用仍取决于实际目标、现有实现及约束。

## 容易混淆的地方

CSS 像素不等于物理像素，移动视口高度可变化

## 实施指南

这是候选实施方法，需结合任务范围与项目环境采用。

让尺寸单位对应正确参考对象。

### 关键特征

- CSS 像素、字体相对单位、百分比和视口单位的基准不同。

### 如何落实

- 沿用字号与间距单位规范；百分比高度确认包含块约束，移动全高布局按需求评估动态视口单位及回退。

### 如何验收

- 浏览器缩放、用户字号和移动地址栏变化时内容可见，嵌套 em 不发生意外倍增。

### 常见误用

- 不要把 CSS px 当物理像素，也不要认为百分比高度在任意父容器里都能确定。
