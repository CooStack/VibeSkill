# 算法设计与分析

用于把“更快、最优、找路径、重复计算”转成可检查的问题规模、正确性条件和算法选择。资料入口 S66，见 [sources.md](sources.md)；容器结构另见 [data-structures.md](data-structures.md)。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| AL001 | Algorithm specification; 算法规格 | 什么算正确、输入范围 | 明确输入、输出、前置条件与可验证结果 | 示例通过不等于覆盖所有合法输入 |
| AL002 | Asymptotic analysis; 渐近分析; Big O | 数据翻倍慢多少、时间空间复杂度 | 比较资源用量随问题规模增长的量级 | 大 O 是渐近上界，不是实际耗时或总是紧确界 |
| AL003 | Amortized analysis; 摊还分析 | 数组扩容偶尔慢、均摊成本 | 将昂贵操作成本分摊到整个操作序列 | 摊还不等于按随机输入分布求平均 |
| AL004 | Divide and conquer; 分治 | 拆成子问题再合并 | 将问题分解、递归求解并合并 | 要计入分解和合并成本，不是所有递归都是分治 |
| AL005 | Dynamic programming; DP; 动态规划 | 重复子问题、背包、状态转移 | 定义状态和递推关系并复用子问题结果 | 先证明状态足够；DP 也可能指设计模式等简称 |
| AL006 | Memoization; 记忆化搜索 | 递归反复算相同参数 | 按子问题状态缓存结果，避免重复求值 | 状态依赖外部可变数据时需失效；不等于所有业务缓存 |
| AL007 | Greedy algorithm; 贪心 | 每步选最好、局部最优 | 在满足相应性质时由局部选择获得整体解 | 局部最优通常不能自动推出全局最优 |
| AL008 | Backtracking; 回溯; Pruning | 穷举组合、撤销试探、剪枝 | 逐步构造候选，在不可能成功处分支截断 | 错误剪枝会漏解；最坏时间仍可能指数增长 |
| AL009 | Binary search; 二分查找; Lower bound | 有序列表定位、找最小可行值 | 在有序或单调谓词空间逐步缩小边界 | 必须确认单调性，明确区间开闭和重复值语义 |
| AL010 | Sorting; Stable sort; 排序稳定性 | 相同分数保留原顺序 | 按键排序，稳定排序保留等价键的相对次序 | 比较器须一致；稳定性不等于结果跨运行必然相同 |
| AL011 | BFS; Breadth-first search; 广度优先搜索 | 最少步数、按层遍历 | 用队列逐层探索，无权或等权图可求最少边路径 | 任意带权图最短距离不能直接用普通 BFS |
| AL012 | DFS; Depth-first search; 深度优先搜索 | 深入遍历、环检测、递归爆栈 | 沿分支探索并回退，支持多种图算法 | 有向环检测需要访问状态；迭代版可避免调用栈限制 |
| AL013 | Dijkstra; 最短路 | 非负权路径、地图路程 | 按当前最短距离扩展节点 | 负权边破坏一般适用前提，不把它当所有寻路问题的默认解 |
| AL014 | Bellman-Ford; Negative cycle | 带负权的路径、负环 | 通过松弛求单源距离并检测可达负环 | 可达负环可能让有关目标没有有限最短距离 |
| AL015 | A-star; A*; 启发式搜索 | 搜索目标路径太慢 | 用已走代价与目标估价引导搜索 | 最优性取决于启发式和重开节点等实现条件 |
| AL016 | Topological sort; 拓扑排序 | 任务依赖、构建顺序、依赖环 | 对有向无环图给出满足前后依赖的顺序 | 有环则不存在完整拓扑序；合法序可能不唯一 |
| AL017 | Minimum spanning tree; MST; 最小生成树 | 低成本连通所有节点 | 在无向加权图上选择总权重最小的连通树 | 不等于每对节点的最短路；不连通时得到森林 |
| AL018 | Strongly connected components; SCC | 相互依赖、循环依赖分组 | 将有向图划分为互相可达的极大节点集合 | 与无向连通分量、强连通整个图不同 |
| AL019 | Maximum flow; Min cut; 最大流最小割 | 容量分配、网络运输 | 在容量约束网络上求可输送量或割 | 容量模型不自动包括成本、时间与整数业务约束 |
| AL020 | Sliding window; Two pointers; 双指针 | 连续区间、滑动窗口去重 | 利用可增量维护的区间状态减少重复扫描 | 能否单调移动边界取决于具体条件，负数可能破坏假设 |
| AL021 | Prefix sum; Difference array; 前缀和与差分 | 区间求和、批量范围更新 | 用累积表示加速查询，或用变化量延迟展开更新 | 二者互相关联但用途不同；在线混合更新查询需另选结构 |
| AL022 | Randomized algorithm; Monte Carlo; Las Vegas | 随机算法、概率正确性 | 区分可能有结果误差与保证正确但耗时随机的算法 | 随机测试和随机算法不是同一件事，需描述失败概率 |
| AL023 | Approximation algorithm; 近似算法 | 最优太慢、容许近似 | 用可证明的近似质量换取计算可行性 | 启发式不自动具有近似比保证 |
| AL024 | Online algorithm; Streaming algorithm | 数据流只能看一遍、未来未知 | 在线算法边接收边决策，流算法强调受限存储处理流 | 二者有交集但并非同义；明确可回看、延迟和误差预算 |
