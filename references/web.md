# 网页与 Web 平台概念

检索分组：地址与传输、文档与搜索、可访问性、浏览器与存储、性能。
网页关注文档和平台；前端组件实现见 [frontend.md](frontend.md)。来源入口：S01、S03、S09、S10，见 [sources.md](sources.md)。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| WB001 | URL; URI; 路径 Path; 查询 Query; Fragment | 链接参数、锚点 | 区分资源定位、查询参数与片段 | URL fragment 通常不随 HTTP 请求发送 |
| WB002 | DNS; 域名 Domain | 域名打不开、解析 | 将名称解析到服务所需记录 | DNS 解析成功不代表应用健康 |
| WB003 | HTTP; Method; Status code | 404、请求返回错误 | 定义请求响应语义和状态 | 应用错误与网络故障需分别处理 |
| WB004 | HTTPS; TLS; 证书 Certificate | 安全连接、证书错误 | 认证端点并保护传输 | 不能替代应用权限或数据存储保护 |
| WB005 | Origin; 同源策略 SOP | 不同域名访问 | Origin 由协议、主机、端口构成 | 同站 Site 与同源不是同一概念 |
| WB006 | CORS; 预检 Preflight | 跨域报错、OPTIONS | 服务器声明允许浏览器读取的跨源响应 | 不是服务端鉴权或 CSRF 防御的替代 |
| WB007 | CSP; Content Security Policy | 限制脚本来源 | 限制页面资源及执行策略 | 不能代替安全编码和输出处理 |
| WB008 | XSS; 上下文编码; Sanitization | 用户内容执行脚本 | 控制不可信内容进入执行或危险解析上下文 | HTML 清洗、文本编码、URL 校验不同 |
| WB009 | CSRF; SameSite; 防伪令牌 | 被诱导发请求、跨站提交 | 防止浏览器附带身份凭据执行非预期操作 | Cookie 属性及令牌策略需结合实际场景 |
| WB010 | Cookie; Secure; HttpOnly | 浏览器自动带登录凭据 | Cookie 受作用域、有效期及属性控制 | HttpOnly 防 JS 读取，不阻止所有滥用 |
| WB011 | HTTP 缓存; Cache-Control; ETag; 304 | 页面资源老不更新 | 管理缓存新鲜度与条件再验证 | no-cache 不等于禁止存储 |
| WB012 | CDN; 边缘缓存 Edge cache | 全球访问慢、静态资源 | 就近分发并减少源站压力 | 私有响应、缓存键及失效必须正确 |
| WB013 | 重定向 Redirect; 301; 302; 307; 308 | 换地址、登录跳转 | 指示客户端转向另一个位置 | 永久性与方法保留语义应分别核对 |
| WB014 | 语义 HTML; Landmark | 页面结构、读屏理解 | 用元素表达内容职责与导航区域 | 不把所有内容都做成 div |
| WB015 | 元信息 Metadata; title; meta description | 标签页标题、搜索摘要 | 描述文档身份及内容 | 搜索引擎可重写摘要，不保证展示 |
| WB016 | SEO; Crawling; Indexing | 搜不到、搜索收录 | 让内容可发现、可抓取、可理解 | 收录与排名不同，不能保证排名 |
| WB017 | robots.txt; Sitemap; noindex | 不让搜索收录、站点地图 | 分别管理抓取提示、URL 发现与索引指令 | robots.txt 不是访问控制，阻抓取不保证去索引 |
| WB018 | Canonical; 规范网址 | 重复页面、带参数同内容 | 声明首选内容地址 | 是搜索信号，不是强制重定向 |
| WB019 | Structured data; 结构化数据 | 富媒体搜索结果 | 用机器可读词汇描述内容 | 标记不保证获得增强搜索展示 |
| WB020 | Open Graph; 社交卡片 | 分享链接预览 | 为社交抓取提供标题、图片等元信息 | 平台缓存和支持范围各异 |
| WB021 | 响应式 Responsive; Viewport; Breakpoint | 手机适配、宽屏 | 随可用空间重排内容 | 不只是把桌面整体缩小 |
| WB022 | 渐进增强 Progressive enhancement | 老浏览器也能用 | 先提供核心功能，再增添增强体验 | 与悄悄丢失关键功能不同 |
| WB023 | 无障碍 Accessibility; a11y | 键盘操作、读屏、可访问 | 支持不同感知、操作与认知需求 | 不是仅加 alt 或自动评分达标 |
| WB024 | WCAG; 可感知/可操作/可理解/健壮 | 无障碍验收 | 用标准组织可验证的访问要求 | 具体版本及等级要核对，不泛称合规 |
| WB025 | ARIA; 可访问名称 Accessible name | 图标按钮读什么 | 向辅助技术表达名称、角色与状态 | 优先原生语义；ARIA 不会自动添加交互 |
| WB026 | 焦点 Focus; Tab 顺序; 焦点陷阱 | 弹窗键盘乱跳 | 管理键盘当前位置及合理移动 | 模态需约束焦点并关闭后恢复，普通页面不困住焦点 |
| WB027 | 替代文本 Alt text; 字幕 Captions | 图片说明、视频听不见 | 提供等价信息 | 装饰图与承载信息的图处理不同 |
| WB028 | 对比度 Contrast; Reduced motion | 看不清、动画眩晕 | 提高可辨识性并尊重减少动态偏好 | 颜色不能作为唯一信息通道 |
| WB029 | 表单语义 Label; Autocomplete; Validation | 输入提示、自动填充 | 建立字段名称、用途及错误关联 | Placeholder 不替代持久标签 |
| WB030 | History API; 深链接 Deep link | 刷新 404、返回上一页 | 让应用状态与可导航 URL 对应 | 客户端路由需服务端回退或匹配 |
| WB031 | localStorage; sessionStorage | 刷新后保留、当前标签页 | 同步键值存储；寿命及作用域不同 | 不放敏感凭据，容量有限且可能不可用 |
| WB032 | IndexedDB | 本地大量结构化数据 | 浏览器事务型结构化存储 | 仍需配额、迁移和数据丢失策略 |
| WB033 | Service Worker; PWA; 离线 Offline | 断网还能用、安装网页 | 拦截受控请求并组织离线或应用体验 | 不保证后台一直运行，升级缓存需设计 |
| WB034 | WebSocket; SSE; Polling | 实时聊天、进度推送 | 双向连接、服务端事件流或周期请求 | 按方向、代理兼容、连接规模选用 |
| WB035 | WebRTC | 音视频通话、点对点 | 提供实时媒体及数据通道 | 仍可能需要信令及中继服务 |
| WB036 | Core Web Vitals; LCP; INP; CLS | 首屏慢、点击迟钝、页面跳 | 分别观察主要内容加载、交互响应、布局偏移 | 指标与阈值以当前官方文档为准 |
| WB037 | TTFB; 关键渲染路径 | 第一字节慢、白屏 | 拆分网络/服务响应与页面渲染成本 | 不把所有慢都归因于前端代码 |
| WB038 | Lazy loading; 预加载 Preload; Prefetch | 图片按需、提前加载 | 调整资源下载时机与优先级 | 滥用预加载会抢占关键资源 |
| WB039 | 响应式图片 srcset; sizes; picture | 手机图片太大、不同裁切 | 按显示条件提供合适资源 | 设备像素比和布局宽度都影响选择 |
| WB040 | 国际化 i18n; 本地化 l10n; RTL | 多语言、日期货币 | 分离可本地化内容并适配地区习惯 | 不只是字符串翻译，还涉及布局与时区 |
| WB041 | Canvas; SVG; WebGL; WebGPU | 网页画图、交互三维 | 分别提供位图画布、矢量文档及 GPU 接口 | 无障碍、命中测试及兼容成本不同 |
| WB042 | 浏览器权限 Permissions; 安全上下文 | 摄像头、定位、剪贴板 | 按受控授权使用敏感能力 | 不保证所有浏览器或嵌入环境可用 |
