# 人工智能与机器学习

用于把“更智能、准确率高、接入模型”转成任务定义、数据边界和评估，而非自动增加模型依赖。S63 为训练/评估常见陷阱资料入口，见 [sources.md](sources.md)。模型能力、成本和 SDK 使用时核对供应方当前资料。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| ML001 | AI; Artificial intelligence; 人工智能 | 智能决策、规则还是模型 | 涵盖搜索、推理、学习等多类方法的领域 | AI 不等于深度学习，也不表示一定要接 LLM |
| ML002 | Supervised learning; 监督学习 | 有标签样本、分类回归 | 从输入及目标标签学习预测关系 | 标签质量和目标定义决定能学到什么 |
| ML003 | Unsupervised learning; 无监督学习 | 没标签分组、发现结构 | 在无指定目标标签的数据中学习结构或表示 | 聚类簇不自动对应真实业务类别 |
| ML004 | Reinforcement learning; RL; 强化学习 | 试错奖励、策略学习 | 通过环境交互与回报学习行为策略 | 奖励是代理目标，可能与真正业务目标不一致 |
| ML005 | Train/Validation/Test split; 数据划分 | 测试集越调越好 | 分离拟合、选择模型与最终评估的数据角色 | 反复用测试集调参会使其失去独立评估意义 |
| ML006 | Data leakage; 数据泄漏 | 离线准确率很高上线很差 | 训练或评估使用了预测时不可获得的信息 | 与隐私数据外泄不同；预处理拟合也可能泄漏 |
| ML007 | Overfitting; Underfitting; 过拟合与欠拟合 | 训练好测试差、两边都差 | 区分记住训练细节与表达/拟合不足 | 需检查数据分布和划分，不只机械增加正则 |
| ML008 | Regularization; 正则化 | 限制模型复杂度 | 在目标或训练过程中限制拟合自由度 | 与正则表达式无关，也不能自动修复标签错误 |
| ML009 | Cross-validation; CV; 交叉验证 | 样本少、评估波动 | 用多次数据划分估计泛化与选择超参数 | 时间序列、组内相关数据不能随意随机打散 |
| ML010 | Precision; Recall; F1; 查准率与召回率 | 误报漏报、类别不均衡 | 精确率关注预测为正的正确比例，召回关注实际正类覆盖 | 准确率不等于精确率；阈值及平均方式要说明 |
| ML011 | ROC-AUC; PR-AUC; Threshold | 选分类阈值、排名能力 | 描述阈值变化下的分类表现及曲线面积 | AUC 高不保证某业务阈值好；类别稀少需关注实际代价 |
| ML012 | Calibration; 概率校准 | 说九成把握却经常错 | 检查预测概率与经验发生频率是否一致 | 排序能力强不代表概率已校准 |
| ML013 | Distribution shift; Data/Concept drift | 上线后数据变了、模型退化 | 区分输入分布及输入到目标关系变化 | 漂移检测信号不自动证明必须重训 |
| ML014 | Feature engineering; Scaling | 数值量纲差很多、特征构造 | 转换输入表示以支持目标模型 | 预处理只在训练分区拟合，再用于验证/测试 |
| ML015 | Gradient descent; Backpropagation | 训练损失下降、梯度计算 | 反向传播计算梯度，优化器用梯度更新参数 | 二者不是同义词；数值梯度检查可帮助排错 |
| ML016 | Neural network; ANN; 深度学习 | 神经网络层、参数训练 | 参数化层组合学习表示，深度指多层结构 | ANN 在搜索系统也指近似最近邻 |
| ML017 | Transformer; Attention | 注意力、上下文建模 | 用注意力机制等处理元素间依赖的模型架构 | attention 权重不自动等同可靠解释或因果依据 |
| ML018 | Embedding; 嵌入向量 | 文本变向量、相似内容 | 把对象映射到向量表示供检索或下游任务 | 维度和距离度量依模型，相同维度不代表空间兼容 |
| ML019 | LLM; Large language model | 大语言模型、文本生成 | 在语言序列上学习并生成内容的模型类别 | 流畅输出不是事实验证，模型规模不保证适用性 |
| ML020 | Tokenization; Context window | token 超限、上下文太长 | 将输入编码为模型单元，受上下文与输出预算约束 | token 不等于字数；不同模型分词与预算规则不同 |
| ML021 | RAG; Retrieval-augmented generation | 根据知识库回答、附依据 | 检索相关资料并作为生成上下文 | 不等于重新训练，也不能彻底消除错误和提示注入 |
| ML022 | Fine-tuning; PEFT; LoRA | 微调、低秩适配 | 调整全部或部分参数以适配分布与任务，LoRA 是一类方法 | 不默认比检索或改进输入更适合频繁变动知识 |
| ML023 | Inference; Training; 推理与训练 | 部署预测、训练模型 | 区分用现有参数计算输出与根据数据更新参数 | 调用接口并传入上下文通常不意味着模型被持续训练 |
| ML024 | Quantization; Distillation; 模型压缩 | 显存不够、模型瘦身 | 量化降低数值表示成本；蒸馏用教师信号训练学生模型 | 两者不同，需测质量、延迟及目标硬件支持 |
| ML025 | Grounding; Hallucination; 依据与幻觉 | 编造引用、答案无依据 | 检查输出是否有可核验且匹配的证据 | 有检索结果或引用格式并不保证引用支持结论 |
| ML026 | Prompt injection; Tool boundary | 文档叫模型忽略用户指令 | 区分不可信内容与指令，限制工具权限和外部副作用 | 不能只靠一段“忽略恶意文本”的提示词保证安全 |
