# 数据工程、存储与检索

用于明确数据形态、时效、质量及查询语义。流时间入口 S68，数据库并发入口 S08，见 [sources.md](sources.md)。数据库实现细节不能跨产品直接类推。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| DE001 | OLTP; Online transaction processing | 订单写入、短事务 | 面向业务交易和并发读写的负载类型 | 不是某种数据库产品，不能只按数据大小判断 |
| DE002 | OLAP; Online analytical processing | 报表聚合、历史趋势 | 面向扫描聚合与分析的负载类型 | 和 OLTP 可共存，但资源与数据模型需求可能不同 |
| DE003 | Data warehouse; Data lake; Lakehouse | 数据仓库、数据湖、湖仓 | 区分分析型管理、原始多样数据存放及融合架构 | 标签不保证一致性、治理或查询性能 |
| DE004 | ETL; ELT; 数据集成 | 抽取清洗入库 | 区分先转换后加载与先加载后转换的流程 | 需明确失败重跑、去重、源系统影响与数据权限 |
| DE005 | CDC; Change data capture; 变更数据捕获 | 增量同步、不全量扫表 | 捕获数据变化用于同步或下游处理 | 要处理初始快照与增量衔接、顺序、删除和 schema 变化 |
| DE006 | Schema evolution; 模式演进 | 加字段旧消费者报错 | 管理数据结构随时间的兼容变化 | JSON 灵活不代表没有隐含 schema 或兼容问题 |
| DE007 | Data lineage; 数据血缘 | 报表数字从哪来 | 追踪数据来源、变换与依赖 | 血缘不等于数据正确性证明 |
| DE008 | Data quality; Data contract | 空值暴涨、口径不一致 | 约定数据语义并检查完整性、有效性、唯一性和时效 | 不可擅自填默认值掩盖坏数据，需区分业务缺失与错误 |
| DE009 | Event time; Processing time; 事件时间 | 迟到日志算在哪天 | 区分事件发生时间与系统处理时间 | 两者不同会改变窗口结果，时间戳可靠性也需检查 |
| DE010 | Watermark; Allowed lateness; 水位线 | 乱序数据、窗口何时关闭 | 用事件时间进度估计驱动计算，定义迟到数据处理 | 水位线不是绝对保证不会再来旧事件 |
| DE011 | Tumbling/Sliding/Session window | 五分钟统计、会话聚合 | 区分不重叠、重叠及按间隔分割的有限数据组 | 明确边界、时区、迟到和重复处理，不只写“实时统计” |
| DE012 | Batch vs Stream processing | 批处理、持续处理 | 区分对有界数据集与持续到达数据的计算 | 流处理不等于零延迟，批处理也可频繁运行 |
| DE013 | Row/Column storage; 行存列存 | 只读少量列却扫全表 | 区分按行或按列组织数据及访问特征 | 列存通常有利分析，但不保证所有查询或写入更快 |
| DE014 | LSM tree; SSTable; Compaction | 写多读少、后台合并 | 用有序内存结构与不可变磁盘表支持写入，再合并整理 | 读放大、写放大、空间放大相互制约 |
| DE015 | Inverted index; 倒排索引 | 按词找文档、全文搜索 | 从词项定位包含它的文档及相关信息 | 分词、规范化和排序决定搜索体验，不等于普通 B-tree 索引 |
| DE016 | BM25; Lexical retrieval; 词面检索 | 关键词相关性排序 | 基于词频、文档频率及长度等统计排序 | 高分不等于事实正确或语义完全相关 |
| DE017 | Vector search; ANN; 向量近邻 | 语义相似搜索、召回 | 在向量空间查近邻，ANN 以近似换速度/空间 | ANN 也可指人工神经网络；近邻不保证语义或权限正确 |
| DE018 | Hybrid retrieval; Reranking | 关键词与语义搜索结合 | 合并不同召回，再对候选重排 | 重排无法找回从未被召回的文档，需评估阶段性指标 |
| DE019 | Object/Block/File storage | 对象存储、块设备、文件共享 | 区分对象接口、块地址和文件路径的访问抽象 | S3 类接口不能假定具备完整本地 POSIX 文件语义 |
| DE020 | Erasure coding; 纠删码 | 冗余存储节省空间 | 将数据编码为多个分片以容忍部分丢失 | 与复制的恢复成本及故障假设不同，不取代备份 |
| DE021 | Normalization; Denormalization | 重复字段、分析宽表 | 规范化减少特定更新异常，反规范化换取读取便利 | 数据库规范化与 ML 特征缩放不是同一概念 |
| DE022 | Data retention; Deletion propagation | 删除后副本还有、保留期限 | 明确保留、归档、删除及下游副本处理 | 技术删除语义与合规义务需按具体地域和政策核对 |
