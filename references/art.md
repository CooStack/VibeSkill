# 美术与视觉制作概念

检索分组：造型与构图、色彩光影、绘画与风格、数字图像、材质与动效。
相邻领域：[设计](design.md)、[建模](modeling.md)、[游戏渲染](game.md)。来源入口：S05、S06、S16，见 [sources.md](sources.md)。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| AR001 | Art direction; 美术指导; Style guide | 统一画风、艺术方向 | 约定形状、色彩、材质、光照及表现规则 | 单张参考图不等于完整风格规范 |
| AR002 | Moodboard; Reference board | 氛围参考、参考拼板 | 归纳希望保留的视觉特征 | 区分学习特征与直接复制具体作品 |
| AR003 | Concept art; 概念设计; Key art | 世界观设定、宣传主视觉 | 概念图探索设计；主视觉凝练展示 | 宣传图不必满足生产资产约束 |
| AR004 | Model sheet; Turnaround; 角色设定三视图 | 角色前侧后、造型一致 | 明确比例、结构和跨视角特征 | 透视插画不能直接替代正交设定 |
| AR005 | Shape language; 形状语言 | 角色看起来强壮或危险 | 用几何轮廓关系表达视觉性格 | 避免将文化联想当普适定律 |
| AR006 | Silhouette; 剪影; Readability | 缩小后认不出、轮廓糊 | 用外轮廓与负形保持辨识 | 内部细节无法补救所有轮廓问题 |
| AR007 | 比例 Proportion; 解剖 Anatomy; Gesture | 人体不对、动作僵硬 | 分别处理尺寸关系、结构与动态趋势 | 风格化变形也需要一致的结构逻辑 |
| AR008 | Composition; 构图; Focal point | 画面散、不知道看哪里 | 组织视觉重心、动线和信息分配 | 三分法等只是工具，不是硬规则 |
| AR009 | Negative space; 负形; Tangency | 轮廓粘连、空间拥挤 | 用空隙分隔形体并避免含混接触 | 负形不只是空白背景 |
| AR010 | Perspective; Vanishing point; Foreshortening | 透视不对、近大远小 | 将空间结构投影为画面关系 | 正交、等距和透视投影不同 |
| AR011 | Atmospheric perspective; 空气透视 | 远景没层次 | 用介质造成的对比和色彩变化表达距离 | 不简单等于所有远景都发蓝 |
| AR012 | Value; 明度; Value grouping | 黑白看不清、亮暗混乱 | 用亮暗分组建立结构与焦点 | 色相丰富不能替代明度组织 |
| AR013 | Hue; Saturation; Value; 色相/饱和度/明度 | 调颜色、太艳、灰 | 分析颜色的不同维度 | HSV 明度并非感知亮度的精确度量 |
| AR014 | 色彩协调 Color harmony; 冷暖关系 | 配色乱、冷暖对比 | 组织颜色间关系与环境氛围 | 配色公式不保证好看或可读 |
| AR015 | 色域 Gamut; 色彩空间 Color space; ICC | 导出变色、屏幕色差 | 定义颜色表示与设备转换关系 | 色彩空间、配置文件与位深不同 |
| AR016 | sRGB; Linear light; Gamma | 混色发暗、光照不对 | 区分编码颜色和适合光计算的线性量 | 颜色贴图与数据贴图不可一律同样转换 |
| AR017 | Bit depth; Banding; Dithering | 渐变断层、颜色数量 | 位深影响量化精度；抖动分散误差 | 提高位深不能恢复已丢失细节 |
| AR018 | Key/Fill/Rim light; 主光/补光/轮廓光 | 立体感、主体分离 | 用不同照明职责控制形体与分离 | 三点布光不是每张图的必选模板 |
| AR019 | Form shadow; Cast shadow; Terminator | 阴影不对、明暗交界线 | 区分自身背光、投影及光暗过渡 | 阴影边缘受光源尺寸与距离影响 |
| AR020 | Occlusion; 接触阴影; Ambient occlusion | 接触面漂浮、缝隙暗 | 表达局部遮蔽及接触关系 | AO 不是所有间接光或污渍 |
| AR021 | Specular; Roughness; Reflection | 太塑料、太亮、金属感 | 区分镜面响应、微表面粗糙程度与反射 | 粗糙度不是反射强度的同义词 |
| AR022 | Subsurface scattering; SSS; 次表面散射 | 皮肤蜡感、透光耳朵 | 描述光进入材料内部再出射 | 与透明折射或简单发光不同 |
| AR023 | Edge control; 硬边/软边/失边 | 画面死板、焦点不清 | 按结构、光照与视觉重点控制边缘 | 全部模糊并不等于自然 |
| AR024 | Brushwork; 笔触; Painterly | 油画感、手绘感 | 用笔触尺度、方向与覆盖组织形体 | 不是在完成图上叠一层统一纹理 |
| AR025 | Stylization; Realism; Exaggeration | 风格化、写实、夸张 | 有选择地提炼或模拟可见特征 | 风格化不等于低多边形或低质量 |
| AR026 | Cel shading; Toon shading | 卡通分层阴影、描边 | 离散化光影并设计图形化材质响应 | 不是所有动漫美术都必须使用 |
| AR027 | Pixel art; 像素画; Pixel grid | 8 位、复古小图、像素角色 | 有意识组织像素簇及有限分辨率 | 缩小照片或马赛克滤镜不等于像素设计 |
| AR028 | Pixel cluster; Selective outline; Hue shifting | 像素轮廓僵、阴影脏 | 通过像素簇、选择性描边和色相变化造型 | 保持统一像素尺度及轮廓节奏 |
| AR029 | Raster; Vector; Resolution; PPI/DPI | 图片放大糊、印刷清晰度 | 区分像素图与几何表示、像素尺寸及输出密度 | 修改 DPI 元数据不会凭空增加细节 |
| AR030 | Alpha; Straight/Premultiplied alpha | 透明边缘黑边、抠图 | 表示覆盖/透明，并约定颜色是否已乘 alpha | 混合公式与数据约定必须一致 |
| AR031 | Layer; Mask; Clipping mask | 非破坏修改、局部调整 | 用图层与遮罩分离内容及可见范围 | 删除像素与遮罩隐藏可逆性不同 |
| AR032 | Blend mode; Multiply; Screen | 叠色、光效合成 | 按公式组合前景与背景颜色 | 混合结果受工作色彩空间影响 |
| AR033 | Texture; Seamless; Tileable | 平铺纹理、边缘接缝 | 让纹理在重复边界连续 | 无接缝不等于看不出重复图案 |
| AR034 | Albedo/Base color; Normal; Roughness; Metallic | 材质贴图一套、PBR 贴图 | 分别存储底色、表面方向、粗糙和金属性 | 非颜色通道通常按数据解释，需核对引擎 |
| AR035 | Trim sheet; Decal; Atlas | 共用细节、贴花、合图 | 复用条带材质、覆盖局部细节或组织多图 | 与网格 UV 和采样留边共同设计 |
| AR036 | Sprite; Sprite sheet; Atlas | 二维角色帧、切图 | Sprite 为精灵单元，表/图集组织图像 | 帧原点、边距和裁剪信息要一致 |
| AR037 | Keyframe; In-between; Timing; Spacing | 动画节奏、动作生硬 | 关键姿态、中间姿态、持续时间和间距分布 | 更多帧不自动获得更好动作 |
| AR038 | Squash/stretch; Anticipation; Follow-through | 动作没重量、缺预备动作 | 用变形、预备和延续表达意图及惯性 | 依材质与风格控制程度 |
| AR039 | Smear; Motion blur; 拖影 | 高速动作读不清 | 用造型或时间积分表达运动连续性 | 模糊过多会损害交互读数 |
| AR040 | VFX shape/timing; 特效层次 | 爆炸没重点、技能不好读 | 组织预警、爆发、持续和消散 | 玩法识别优先于无差别堆粒子 |
| AR041 | Compositing; Color grading; LUT | 后期合成、统一色调 | 合并渲染层并调整最终色彩表达 | 调色不能修复全部照明或材质错误 |
| AR042 | Look development; Lookdev | 材质灯光一起调、外观开发 | 在一致观察条件下确认资产外观 | 需明确测试环境与最终显示条件 |
