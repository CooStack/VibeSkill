# 后端概念

检索分组：接口与契约、身份与安全、数据与存储、并发与分布式、运行与质量。
相邻领域：[网页](web.md)、[前端](frontend.md)、[游戏联机](game.md)。来源入口：[sources.md](sources.md) 的 S01、S02、S08、S09。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| BE001 | 接口契约 API contract; Schema | 前后端字段对不上、返回格式 | 约定输入、输出、错误、兼容规则 | Schema 校验不能替代业务校验 |
| BE002 | REST; 资源 Resource | 增删改查接口、资源地址 | 用资源标识及 HTTP 语义组织接口 | REST 不等于所有接口只用 JSON |
| BE003 | RPC; gRPC | 服务间调用、强类型契约 | 以远程过程及消息契约表达调用 | 远程调用仍有延迟与部分失败 |
| BE004 | GraphQL; 查询语言 | 客户端按需取字段 | 用类型化查询描述所需数据 | 要限制复杂度并处理授权及 N+1 |
| BE005 | Webhook; 回调通知 | 外部系统通知我、支付通知 | 服务向约定端点推送事件 | 需验签、防重放、重试及去重 |
| BE006 | 分页 Pagination; 游标 Cursor; Offset | 列表翻页、滚动加载 | 分段查询；游标表达排序位置 | 稳定排序必要；游标不必是主键 |
| BE007 | 版本化 Versioning; 向后兼容 | 老客户端不能坏 | 管理契约演进与兼容窗口 | 新增必填字段也可能破坏兼容 |
| BE008 | 幂等 Idempotency; 幂等键 | 重复提交、重试重复下单 | 同一意图多次执行不重复产生效果 | 仅禁用按钮不能保障服务端幂等 |
| BE009 | 认证 Authentication; AuthN | 你是谁、登录 | 核验主体身份 | 与“能做什么”的授权分开 |
| BE010 | 授权 Authorization; AuthZ; RBAC; ABAC | 角色权限、只能看自己的 | 按角色或属性约束资源操作 | UI 隐藏不是权限控制；防越权 |
| BE011 | Session; Cookie; JWT | 登录态、令牌、退出登录 | Session 是会话；Cookie 是载体；JWT 是令牌格式 | JWT 不等于加密，也不天然支持即时撤销 |
| BE012 | OAuth 2.0; OIDC; SSO | 第三方登录、统一登录 | OAuth 管委托访问；OIDC 补充身份层 | 不把 OAuth 本身当身份认证协议 |
| BE013 | 输入验证 Validation; 参数化查询 | 非法输入、SQL 注入 | 按边界验证数据并分离查询与参数 | 转义、验证和授权是不同职责 |
| BE014 | 密码哈希 Password hashing; Salt | 保存密码、密码泄露 | 使用适合密码的带盐成本型哈希 | 不用可逆加密或快速通用哈希替代 |
| BE015 | 密钥管理 Secrets; 最小权限 | API key、配置泄露 | 限制密钥分发、暴露和权限范围 | 不将密钥写入客户端、仓库或日志 |
| BE016 | 限流 Rate limiting; Quota | 刷接口、防滥用、配额 | 限制时间窗口请求或资源消耗 | 与并发限制、身份授权不同 |
| BE017 | 关系模型 Relational model; 主外键 | 表关联、数据一致 | 用关系及约束表达数据结构 | 不用应用约定取代必要数据库约束 |
| BE018 | 规范化 Normalization; 反规范化 | 重复字段、联表太多 | 分解数据减冗余，或为读取有意冗余 | 反规范化要定义更新与修复责任 |
| BE019 | 索引 Index; B-tree; 复合索引 | 查询慢、筛选排序 | 以额外结构减少访问成本 | 索引增加写入及空间成本，需看执行计划 |
| BE020 | 查询计划 Query plan; EXPLAIN | SQL 为什么慢 | 分析扫描、连接、估算与实际开销 | EXPLAIN ANALYZE 可能真实执行查询 |
| BE021 | 事务 Transaction; ACID | 转账、同时成功或失败 | 在事务边界维护原子性及一致性等性质 | 单库事务不自动覆盖外部服务 |
| BE022 | 隔离级别 Isolation; MVCC | 脏读、幻读、并发读取 | 定义并发事务可见性，MVCC 保留多版本 | 引擎对同名级别的具体行为需核对 |
| BE023 | 乐观锁 Optimistic locking; CAS | 防覆盖别人修改、版本号 | 提交时验证版本或条件是否仍成立 | 冲突需要重试或向用户解决 |
| BE024 | 悲观锁 Pessimistic locking; 死锁 Deadlock | 抢库存、锁住数据 | 通过锁协调访问 | 锁顺序、粒度与超时影响吞吐 |
| BE025 | ORM; N+1; 批量加载 | 循环查数据库、实体映射 | ORM 映射对象；批量查询减少逐项往返 | ORM 不消除 SQL 成本与事务知识 |
| BE026 | 迁移 Migration; 回填 Backfill | 修改表结构、补历史数据 | 演进结构和历史内容 | 兼容部署、锁表及回滚能力需单独评估 |
| BE027 | 缓存 Cache; TTL; Invalidation | 重复查询、加速、旧数据 | 复用结果并定义过期或失效机制 | 缓存不是唯一事实来源，明确陈旧容忍 |
| BE028 | Cache-aside; 缓存穿透/击穿/雪崩 | 热点过期、缓存失效打爆库 | 按访问路径设计回源与保护 | 空值缓存、请求合并、过期抖动解决不同问题 |
| BE029 | 消息队列 Queue; Pub/Sub | 异步排队、事件广播 | 队列分配工作；发布订阅分发事件 | 通常需考虑重复、乱序和积压 |
| BE030 | 投递语义 At-least-once; At-most-once; Exactly-once | 消息不能丢也不能重复 | 约定投递或处理保证所在范围 | 不轻易承诺跨系统端到端恰好一次 |
| BE031 | 重试 Retry; 退避 Backoff; Jitter | 网络失败再试 | 在有限预算内处理暂时失败 | 非幂等操作需去重；避免重试风暴 |
| BE032 | 超时 Timeout; Deadline; 取消 Cancellation | 一直等待、请求卡死 | 限定整个调用链等待与计算预算 | 客户端超时不意味着服务端未执行 |
| BE033 | 熔断 Circuit breaker; 隔舱 Bulkhead | 下游故障拖垮全部 | 中止持续失败调用、隔离资源消耗 | 熔断与限流目的不同 |
| BE034 | 背压 Backpressure; 负载削减 Load shedding | 消费跟不上、内存涨 | 将过载反馈给上游或拒绝超额工作 | 无限队列不是容量方案 |
| BE035 | 一致性 Consistency; 最终一致 Eventual consistency | 写完读不到、跨节点同步 | 定义副本或系统间可见性保证 | 最终一致仍需收敛机制及冲突规则 |
| BE036 | CAP; 网络分区 Partition | 分布式可用与一致如何选 | 在分区情境讨论一致性与可用性约束 | 不是任何时刻任意“三选二” |
| BE037 | Saga; 补偿事务 Compensation | 跨服务订单流程 | 将分布式流程拆成可补偿步骤 | 补偿不等于数据库回滚，可能再次失败 |
| BE038 | Outbox; CDC | 数据提交了但消息没发 | 事务内记录待发事件，或捕获变更 | 下游仍需处理去重、顺序及重放 |
| BE039 | CQRS; 读写模型分离 | 读写结构差异很大 | 用不同模型处理命令与查询 | 不要求微服务或事件溯源 |
| BE040 | 事件溯源 Event sourcing | 历史状态重放、事件账本 | 用事件序列作为状态来源 | 审计日志本身不是事件溯源 |
| BE041 | 单体 Monolith; 模块化单体; 微服务 | 拆服务、独立发布 | 定义部署边界和模块职责 | 服务数量不是架构质量指标 |
| BE042 | 负载均衡 Load balancing; 水平扩展 | 多台机器、扩容 | 分摊流量并增减实例 | 共享状态、连接与热点仍需处理 |
| BE043 | 分片 Sharding; 复制 Replication | 数据太大、读副本 | 分片分配数据，复制保留副本 | 复制不等于备份，分片增加跨片成本 |
| BE044 | 可观测性 Observability; Logs; Metrics; Traces | 找故障、链路慢 | 用日志、指标、追踪关联系统行为 | 避免敏感日志和无界指标标签 |
| BE045 | SLI; SLO; 错误预算 Error budget | 可用率目标、延迟目标 | 指标衡量体验，目标定义可靠性承诺范围 | 平均值掩盖尾延迟，关注百分位 |
| BE046 | 健康检查 Liveness; Readiness | 启动未好就接流量 | 分别判断进程存活及能否承接请求 | 检查错误设计可造成重启风暴 |
| BE047 | CI/CD; 蓝绿 Blue-green; 金丝雀 Canary | 自动发布、逐步上线 | 验证并逐步替换运行版本 | 回滚代码未必能回滚数据迁移 |
| BE048 | 容器 Container; 编排 Orchestration; IaC | 环境一致、自动部署 | 打包运行环境并声明基础设施 | 容器不是完整虚拟机，编排并非总必要 |
| BE049 | 备份 Backup; RPO; RTO; 灾备 | 丢数据怎么办、多久恢复 | 定义可容忍数据丢失和恢复时间 | 需验证恢复，不只确认备份任务成功 |
| BE050 | 单元/集成/契约/端到端测试 | 接口改动不敢上线 | 按边界验证逻辑、依赖、约定及用户流程 | 不以单一覆盖率替代关键行为验证 |
| BE051 | 多租户 Multi-tenancy; 租户隔离 | 多家公司共用系统 | 按租户隔离数据、权限和资源 | 过滤条件、缓存键、后台任务都要带隔离语义 |
| BE052 | 后台任务 Job; Scheduler; 工作流 Workflow | 定时处理、长任务进度 | 将请求之外的工作建模为可追踪执行 | 区分调度时间、执行次数和幂等保证 |
