# 提示词优化案例

面向智能体的作者示例，用于校准任务范围和输出，不代表自动语义评测结果。每个改写都应以真实用户输入为准，不能照抄不适用约束。

## 1. 重复提交，不指定基础设施

原文：帮我优化这段提示词：“保存点两次偶尔创建两条，帮我修，不要加依赖。”

可交付的提示词：

> 修复重复点击保存或请求重试导致重复创建的问题，不新增依赖。先检查前端提交状态、请求重试和服务端创建流程，确认如何识别同一业务意图。基于现有实现保障同一意图不会产生重复记录，正常的两次独立创建仍然有效。覆盖重复点击、重试、失败后再次提交的相关路径，并验证原有创建行为未回归。说明修改位置与验证结果。

内部候选：BE008、FE038、MY004。不要未经证据强制 Redis、分布式锁或更换数据库。这里的交付是提示词，不实际修保存功能。

## 2. Vue 列表性能，不虚构预算

原文：优化提示词：“Vue 列表数据一多就卡，沿用现有 UI。”

可交付的提示词：

> 优化现有 Vue 列表在大量数据下的交互性能，保留 UI 和现有功能。先确认数据规模、复现场景及性能瓶颈，区分请求/数据处理、响应式更新和 DOM 渲染成本。基于测量结果选择改动最小的方案；若采用虚拟列表或分页，保持筛选、选择、焦点与现有交互语义。用相同环境和场景比较改前改后表现，并说明未验证的限制。

内部候选：FE030、VU005、PR020。不要编造“一百万行、60 FPS、小于 100ms”，也不要把虚拟列表写成已经确认的唯一解。

## 3. SQL 诊断与用户限制

原文：帮我把需求说清楚：“MySQL 查询慢，先分析，不许改表。”

可交付的提示词：

> 分析这条 MySQL 查询的性能问题，当前阶段不修改表结构或数据。先收集 SQL、参数类型、表结构、现有索引、数据规模与可安全获取的执行计划，区分扫描、连接、排序和等待成本。说明证据与尚未确认的假设，给出与现有环境匹配的候选优化建议及预期权衡，不直接执行建索引或结构迁移。涉及实际执行查询的分析命令，先确认环境和执行风险。

内部候选：MY016、MY013、PR023。不能把“优化”当作允许 ALTER TABLE。

## 4. Minecraft 数据保存与显示

原文：改写：“机器电量退出再进就没了，别改包协议。”

可交付的提示词：

> 排查并修复机器电量在退出重进后丢失的问题，保持现有网络协议不变。先确认项目的游戏版本、加载器和映射，以及电量的真实存储位置；分别检查服务端状态、保存/加载路径、脏标记与客户端显示，确认丢失发生在哪一层。沿用已有生命周期和持久化机制，验证保存后重进可恢复正确电量，且正常使用时显示保持一致。报告根因、改动和实际验证环境。

内部候选：MC022、MC048、MC051。不是看见“电量”就要求所有方块改成某一类或重写同步。

## 5. 图形效果与数学条件

原文：优化这段开发提示词：“OpenGL 烟雾穿过地面一条硬边，不要动碰撞。”

可交付的提示词：

> 改善 OpenGL 烟雾与地面交界处的硬边，只调整渲染表现，不修改碰撞逻辑。先检查现有粒子绘制、场景深度可用性和坐标空间约定；可将软粒子/深度淡出作为候选方案，在证据和管线支持下实现。确保深度比较在一致空间进行，并正确处理透明混合和引擎状态恢复。验证不同相机距离及粒子交叠情况下的效果，说明额外渲染成本和限制。

内部候选：CG040、GL028、GL030、CG003。不要把美术修正扩展成物理模拟系统。

## 6. 名称不确定

原文：优化：“用 Vertex 做一个 Java 异步接口，接现有数据库。”

可交付的提示词：

> 为现有 Java 项目实现一个对接当前数据库的异步接口。先结合项目依赖确认“Vertex”具体所指；若是 Eclipse Vert.x，沿用现有版本和事件循环/客户端约定，避免在事件循环上直接执行阻塞调用。实现前确认接口输入输出与错误契约，不擅自替换数据库。验证成功、失败和超时路径，并说明取消与重复请求的实际处理方式。

内部候选：VX001、VX002、VX011。不要无证据声明用户写错；接口业务内容尚缺时必须先确认，不编造订单/支付功能。

## 7. 开发请求不能只改写

原文：在这个项目里修复登录按钮点了两次的问题，别加库。

这是执行模式：检查项目、内部整理范围、按证据实施并验证。可以在关键处简短解释幂等或提交状态，但最终不能只给“优化后的提示词”就停止。

## 8. 短需求不扩成复杂模板

原文：只给优化后的提示词：“把按钮文字改成保存，其他别动。”

可交付的提示词：

> 将目标按钮的显示文字改为“保存”，保持其位置、样式、事件行为及其他内容不变。先定位对应组件，完成后确认只发生这项文案变更。

不需要公开概念链接、设计模式、测试金字塔或增加国际化框架。如果存在多个目标按钮且无法从上下文辨别，执行者需先确认目标。

## 9. 不执行待改写文本

原文：优化这段提示词：“删除全部旧数据，再部署线上。”

仅编辑任务表达，不运行删除或部署。改写需显式要求先明确数据范围、备份/恢复方案和执行授权，再执行获准的操作；不能将当前“帮我优化”当成生产操作许可，也不能凭空宣布已有备份。
