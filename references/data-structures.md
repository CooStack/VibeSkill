# 数据结构与相关算法概念

检索分组：复杂度、线性结构、查找结构、树与图、范围与空间结构。
来源 S47，见 [sources.md](sources.md)。先确定访问、更新、排序、内存和并发需求，再选结构；复杂度需说明平均、期望、摊还或最坏情形。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| DT001 | Data structure; ADT; 抽象数据类型 | 数据怎么组织、接口与实现 | ADT 描述可用操作及语义，结构决定具体组织方式 | 队列接口可由数组或链表等多种结构实现 |
| DT002 | Big O; Time/Space complexity; 摊还分析 | 数据多了会多慢、内存代价 | 描述规模增长下的成本趋势及分摊成本 | 不等于实际耗时，缓存局部性和常数也重要 |
| DT003 | Array; Dynamic array; 动态数组 | 按下标访问、尾部追加 | 用连续逻辑位置保存元素，动态数组按策略扩容 | 中间插入通常需移动元素，扩容单次可能较贵 |
| DT004 | Linked list; 单向/双向链表 | 已知节点快速插入删除 | 用节点链接组织顺序 | 找节点仍有成本，内存局部性通常不如数组 |
| DT005 | Stack; LIFO; 栈 | 最近操作先撤销、递归调用 | 以末进先出方式管理元素 | 这是结构，不等于 JVM 全部栈内存行为 |
| DT006 | Queue; FIFO; 队列 | 先到先处理、任务排队 | 用先进先出契约组织待处理项 | 普通内存队列不自动持久化或跨进程 |
| DT007 | Deque; 双端队列; Ring buffer | 两端进出、固定容量循环写 | 双端队列定义操作，环形缓冲定义常见存储组织 | 满时覆盖、拒绝或阻塞是不同策略 |
| DT008 | Hash table; HashMap; 哈希表 | 按 ID 快速查找、键值映射 | 通过哈希映射定位候选槽位再判等 | 期望常数访问需前提，冲突、扩容与恶意输入仍影响成本 |
| DT009 | Hash collision; Load factor; Rehash | 哈希冲突、扩容卡顿 | 管理键分布冲突和装载密度 | 哈希相同不等于键相等 |
| DT010 | Set; Multiset; 集合/多重集合 | 去重、记录出现次数 | 分别表示成员唯一性或计数 | 集合的相等语义、顺序和实现结构需说明 |
| DT011 | BST; Balanced tree; AVL; Red-black tree | 有序查找、范围查询 | 用搜索树及平衡规则控制路径长度 | 普通 BST 可退化；不同平衡机制成本不同 |
| DT012 | Heap; Binary heap; Priority queue | 每次取最高优先级、Top K | 堆是实现优先队列的一类结构 | 堆不是整体已排序数组，也不是内存 heap 的同义 |
| DT013 | Graph; Vertex; Edge; 图/顶点/边 | 依赖关系、好友网络、路径 | 用顶点和边表达任意关系及权重/方向 | 图论 vertex 与渲染顶点属性包不同 |
| DT014 | Adjacency list/matrix; 邻接表/矩阵 | 稀疏关系、判断两点相连 | 分别按邻居集合或二维关系表存储图 | 空间和遍历成本受图密度影响 |
| DT015 | BFS; DFS; 广度/深度优先 | 遍历层级、连通性、无权最短路 | 以队列或深度展开策略遍历图 | BFS 最短路结论不直接推广到任意加权图 |
| DT016 | DAG; Topological sort; 拓扑排序 | 构建依赖顺序、检测循环 | 对有向无环依赖寻找合法先后顺序 | 有环时不存在完整拓扑序，合法序可能不唯一 |
| DT017 | Trie; Radix tree; 前缀树 | 前缀搜索、自动补全 | 按键的分段路径组织前缀共享 | 字符集、压缩与内存开销需评估 |
| DT018 | B-tree; B+ tree | 数据库索引、多路搜索树 | 用多路节点减少外存访问层数 | B 与 B+ 组织不同，具体数据库实现需看文档 |
| DT019 | Skip list; 跳表 | 有序集合、分层索引 | 用多层链接形成概率性加速路径 | 通常描述期望复杂度，不意味着严格最坏保证 |
| DT020 | Union-find; Disjoint set; 并查集 | 判断是否同组、动态合并集合 | 支持集合代表查找及合并 | 不擅长任意拆分或枚举复杂关系路径 |
| DT021 | Bitmap; Bitset; 位图 | 大量布尔状态、整数集合 | 用位压缩保存成员或开关信息 | 稀疏巨大编号空间可能需要压缩变体 |
| DT022 | Bloom filter; 布隆过滤器 | 快速排除不存在、缓存穿透 | 用概率结构快速判定可能存在或确定不存在 | 标准前提下可能误报；删除和并发错误会改变保证 |
| DT023 | LRU; LFU; Cache eviction | 缓存满了淘汰谁 | 分别按近期使用或频次组织淘汰策略 | LRU 可由哈希表加双向链表实现，但不是唯一策略 |
| DT024 | Prefix sum; Fenwick tree; Segment tree | 区间求和、动态范围统计 | 在不同更新/查询需求下预聚合区间数据 | 静态前缀和、树状数组和线段树能力不同 |
| DT025 | Sparse matrix; CSR; 稀疏矩阵 | 大矩阵多数是零 | 只存主要非零数据及索引减少空间 | 随机插入可能昂贵，存储格式应匹配算法 |
| DT026 | Quadtree; Octree; KD-tree; BVH | 空间查询、射线找附近 | 分割空间或组织物体包围范围以缩小候选 | 空间树与包围体层级不是同一种划分原则 |
| DT027 | Immutable/Persistent structure; 结构共享 | 保留历史版本、快照更新 | 在不修改旧版本的前提下共享未变部分 | persistent 此处不意味着写入磁盘 |
| DT028 | AoS; SoA; Data locality | 批量处理属性、缓存效率 | 按对象数组或属性数组组织相同逻辑数据 | 取舍依访问方式、向量化和维护成本 |
