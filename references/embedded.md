# 嵌入式、实时系统与物联网

用于澄清硬件接口、截止期限、功耗与失效边界。S69 为实时内核资料入口，S65 为架构入口，见 [sources.md](sources.md)。不是电气接线或安全关键设备的操作手册。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| EM001 | MCU; Microcontroller; 微控制器 | 单片机、板上控制 | 在芯片中集成处理器、存储和外设用于控制任务 | MCU 与 MPU 分类有交集，不能仅按频率推断能力 |
| EM002 | Firmware; Bare metal; 固件与裸机 | 没操作系统的程序 | 固件是设备级软件，裸机指不依赖完整 OS 的执行方式 | 固件也可包含 OS；两者非同义 |
| EM003 | RTOS; Real-time operating system | 实时任务调度 | 支持时间约束任务及可分析调度的操作系统 | 使用 RTOS 不自动证明整个应用满足截止期限 |
| EM004 | Hard/Soft real-time; 硬实时软实时 | 必须准时响应、偶尔迟到 | 区分错过截止期限是否构成不可接受失败 | 实时意味着时限约束，不是“平均很快” |
| EM005 | WCET; Worst-case execution time | 最坏耗时、时间预算 | 在明确平台与执行条件下界定最大执行时间 | 实测最大值通常不能自动证明最坏上界 |
| EM006 | Interrupt; ISR; 中断服务程序 | 外设到数据马上响应 | 在事件到来时转入处理程序 | 可调用 API、阻塞和执行时长受中断上下文限制 |
| EM007 | GPIO; General-purpose I/O | 控制引脚、读取开关 | 配置数字输入输出及相关电气模式 | 电压、电流和上拉规则须查硬件，软件逻辑值不代表接线安全 |
| EM008 | UART; SPI; I2C; 外设总线 | 串口、传感器通信 | 不同连接与时序约定的设备通信接口 | 三者不是可互换别名，电平、地址和时序需分别核对 |
| EM009 | ADC; DAC; 模数与数模转换 | 传感器读数、输出模拟量 | 在连续量与离散数字表示之间转换 | 分辨率不等于精度，采样率也不等于有效带宽 |
| EM010 | PWM; Pulse-width modulation | 调占空比、调光 | 通过脉冲宽度/占空比调节平均作用 | PWM 不等于真正连续模拟电压，负载和滤波影响结果 |
| EM011 | Watchdog; 看门狗 | 程序卡死自动恢复 | 未按约定维持心跳时触发复位或故障处理 | 无条件喂狗可能掩盖业务卡死，复位也需恢复设计 |
| EM012 | Debouncing; 按键消抖 | 按一次触发多次 | 过滤机械触点短时抖动 | 与前端 debounce 有相近思想，但硬件时序与输入特征不同 |
| EM013 | MMIO; Memory-mapped I/O | 读写外设寄存器 | 通过特定地址访问设备状态和控制 | 访问可能有副作用，不能按普通 RAM 任意优化或缓存 |
| EM014 | Bootloader; Secure boot | 启动验证、固件加载 | 引导程序加载后续软件；安全启动验证可信链 | 安全启动不等于软件无漏洞或数据已加密 |
| EM015 | OTA; Firmware update; 空中升级 | 远程更新设备、断电变砖 | 设计传输、校验、版本切换及失败恢复 | 需要授权和兼容检查，不能只保证下载成功 |
| EM016 | IoT; MQTT; QoS | 设备遥测、消息服务质量 | IoT 是设备联网场景，MQTT 提供发布订阅及协议级交付级别 | MQTT QoS 保证范围不是业务外部副作用的全局 exactly-once |
| EM017 | Edge computing; 边缘计算 | 离线也能处理、减少回云 | 在靠近数据或设备的位置计算 | 不必然比云更快或更隐私，需看资源和数据流 |
| EM018 | Power budget; Sleep mode; 功耗预算 | 电池续航、低功耗唤醒 | 在工作负载和唤醒成本下管理能耗 | 瞬时功率与累计能量不同，不能只看休眠电流 |
