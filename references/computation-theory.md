# 计算理论、逻辑与信息

把“有没有通用算法、最优是否算得动、能否无损压缩”转成模型及假设。课程入口 S67，范围入口 S56，见 [sources.md](sources.md)。数学数值工具另见 [mathematics.md](mathematics.md)。

| ID | 概念 / 英文 / 别名 | 需求线索 | 含义与用途 | 边界 / 易混淆 |
| --- | --- | --- | --- | --- |
| TC001 | Computer science; CS; 计算机科学 | 计算机科学整体、计算与信息 | 研究计算、信息表示、算法及实现系统的广泛领域 | 不只编程语言；CS 还可指计算着色器，需语境消歧 |
| TC002 | Finite automaton; DFA; NFA; 有限自动机 | 有限状态识别、词法匹配 | 用有限状态和转移识别正则语言 | DFA/NFA 表达能力相同但状态数量和执行方式不同 |
| TC003 | Regular language; Regular expression | 正则能不能解析嵌套 | 理论正则表达式与有限自动机描述同类语言 | 实用 regex 引擎的反向引用等扩展超出经典模型 |
| TC004 | Context-free grammar; CFG; 上下文无关文法 | 嵌套括号、语法规则 | 用非终结符生成式描述一类语言结构 | CFG 也可指控制流图；文法可有歧义 |
| TC005 | Pushdown automaton; PDA; 下推自动机 | 栈识别嵌套结构 | 在有限控制基础上增加栈的计算模型 | 非确定型与确定型 PDA 的语言能力并不相同 |
| TC006 | Turing machine; 图灵机 | 通用计算模型 | 用抽象状态、带和读写转移刻画可计算过程 | 是理论模型，不按硬件速度直接衡量现实性能 |
| TC007 | Decidability; Undecidability; 可判定性 | 任意程序都能判断吗 | 判定问题是否存在对所有输入都终止并正确回答的算法 | 不可判定不意味着所有受限实例都无法处理 |
| TC008 | Halting problem; 停机问题 | 自动判断所有程序会不会结束 | 一般情形不存在总能正确判定任意程序终止性的算法 | 超时是工程策略，不是一般停机性的证明 |
| TC009 | Reduction; 归约 | 已知难题转成另一个问题 | 通过保持解关系的转换比较问题难度 | 归约方向重要，不能把证明方向颠倒 |
| TC010 | P; NP; 多项式复杂度类 | NP 是不是无法求解 | P 可多项式时间判定；NP 的肯定证据可多项式时间验证 | NP 不代表非多项式，也不是所有 NP 问题都难 |
| TC011 | NP-hard; NP-complete; NP 困难与完全 | 最优排程难、复杂度证明 | NP-hard 至少与 NP 中所有问题一样难；NP-complete 还属于 NP | 最坏情况困难不排除小规模、特殊结构或近似解 |
| TC012 | SAT; SMT; 可满足性 | 约束有没有解、符号求解 | SAT 处理布尔公式，SMT 加入特定理论的约束 | 求解器性能及可判定性依理论组合与规模 |
| TC013 | Propositional/Predicate logic; 命题与谓词逻辑 | 量词、条件约束 | 区分对命题的连接与含对象变量及量词的表达 | 自然语言“任意/存在”的作用域必须明确 |
| TC014 | Invariant; Induction; 不变量与归纳 | 循环每一步都要成立 | 通过基础情况和保持性论证性质 | 只证明保持性不足以证明终止性或初始成立 |
| TC015 | Safety vs Liveness; 安全性与活性 | 不出错也不能一直等 | 安全性约束坏事不发生，活性要求好事最终发生 | 此处 safety 不等同网络安全；活性依公平性等假设 |
| TC016 | Information entropy; 信息熵 | 信息量、压缩极限 | 用概率分布量化平均不确定性 | 单位取决于对数底；熵不是语义价值或“混乱度”万能尺度 |
| TC017 | Lossless/Lossy compression | 无损压缩、牺牲质量变小 | 区分可精确恢复与允许失真的编码 | 不存在把每种输入都严格变短的通用无损编码 |
| TC018 | Error detection/correction; CRC; FEC | 传输位翻转、纠错码 | 加入冗余用于检测或纠正一定错误模式 | CRC 是检错而非密码认证；检错能力受码和错误模型限制 |
| TC019 | Kolmogorov complexity; 描述复杂度 | 最短程序表示数据 | 以生成对象所需最短描述刻画算法信息量 | 一般不可计算，不等于某压缩工具输出长度 |
| TC020 | Church-Turing thesis; 丘奇图灵论题 | 可计算是否等于机器能算 | 关于有效可计算过程与形式模型关系的论题 | 不是现实可高效计算的保证，也非从单一模型内部直接证明的定理 |
